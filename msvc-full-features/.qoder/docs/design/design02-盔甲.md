# 策划案 002：盔甲体系（14 世纪末 ~ 15 世纪初过渡期）

## 时代定位

| 项目 | 说明 |
|------|------|
| 时期 | 约 1375–1425（百年战争中后期） |
| 阶段名称 | **过渡盔甲期**（Transitional Armor） |
| 特征 | 锁子甲（mail）仍为主流基础层，板甲正在快速普及但尚未全覆盖 |
| 代表战役 | 阿金库尔（1415）、尼科波利斯（1396） |

---

## 一、盔甲穿着层次

中世纪盔甲不是"穿一件"，而是**逐层叠加**，不同阶层在"能穿到第几层"上分化：

```
第 1 层：内衣（linen shirt / braies）
  ↓
第 2 层：武装衣 gambeson / aketon（厚棉麻填料，防钝击 + 提供缓冲）
  ↓
第 3 层：锁子甲 hauberk（铁环编制，防割伤 / 对刺击弱）
  ↓
第 4 层：板甲 / brigandine（最大防护层，贵族和重装兵专享）
```

### 映射到 CDDA 穿着层

| 层 | CDDA 部位 | 中世纪对应 |
|----|-----------|------------|
| 贴身层（skin） | 全身 | 亚麻内衣 |
| 正常层（normal） | 全身 | gambeson / 皮甲 |
| 外层（outer） | 躯干为主 | 锁子甲 hauberk |
| 绑缚层（strapped） | 四肢 + 躯干 | 板甲部件（vambrace / cuirass 等） |

### 2.2 颈部

| 盔甲 | 材料 | 覆盖 | 备注 |
|------|------|------|------|

> **Bevor vs Gorget 区分**：Gorget 环绕颈部防护（前喉 + 后颈），主要用于封堵头盔与胸甲之间的缝隙。Bevor 则是面部下半部分的防护（下颌、脸颊下部、前喉），与 sallet 头盔配合形成完整头部防护——sallet 盖住头顶+后脑，bevor 盖住下巴+前喉+脸颊，两者结合达到近似 great helm 的防护但更轻、视野更好。这是 15 世纪中期板甲骑士的标准配置。

## 三、社会阶层 × 盔甲能力矩阵

### 总览表

| 阶层 | 典型配置 | 概要 | 覆盖率 |
|------|----------|------|--------|
| 农民 / 流民 | 亚麻衣 + 可能有毡帽 | 几乎裸奔 | 0~10% |
| 民兵 / 征召兵 | gambeson + kettle hat | 能抗几刀 | 30~50% |
| 雇佣兵 / 轻装步兵 | gambeson + mail hauberk + bascinet | 标准配置 | 60~75% |
| 重装步兵 / 下级骑士 | mail + brigandine + bascinet with visor + 臂甲部分 | 铁乌龟 | 80~90% |
| 骑士 / 高级军官 | 完整过渡期板甲 + 全副武装 | 几乎全覆盖 | 90~95% |
| 领主 / 王室 | 定制全身板甲 | 无人能轻易穿透 | 95%+ |

### 场景化速查
- 野外遇到一个拿矛的民兵：gambeson + kettle hat → 砍躯干几乎没效果，砍四肢和脸
- 强盗头目：mail hauberk + bascinet → 必须用钝器或穿刺武器
- 骑士团遭遇战：过渡期板甲 → 除非有戟/长弓/弩，否则赶紧跑
- 遗迹里发现一副 **Cuirass**：本时期早期胸甲的标志性高端防具，捡到等于赚到

## 四、损伤与防护机制

### 伤害类型对应

| 类型 | 有效武器 | 畏惧的盔甲 |
|------|----------|------------|
| 斩击（Cut） | 剑、斧 | mail、plate 均有效防御 |
| 穿刺（Pierce） | 矛、箭、弩、匕首 | mail 弱，plate 极强 |
| 钝击（Bash） | 锤、棍、权杖（mace） | gambeson 提供缓冲，但 plate 怕变形 |
| 撕裂 | 钉头锤？ | 对 mail 有效（扯断铁环） |

### CDDA 盔甲数据设计原则
- **Gambeson**：高 bash 防御（缓冲），中等 cut 防御，低 pierce（箭能穿）
- **Mail**：极高 cut 防御，中等 pierce（bodkin arrow 能突破），低 bash（钝器撞断骨头）
- **Brigandine / CoP**：高 cut + 中高 pierce，低 bash
- **Plate**：全面超高防御，但有覆盖率盲点（腋、颈、大腿内侧、面甲缝）
- **叠加规则**：gambeson + mail + plate 三层一起穿的部位 → 真正的铁罐头，但重量和精力消耗巨大

## 五、重量与累赘度设计

| 配置 | 大致重量 | 对 CDDA 的影响 |
|------|----------|----------------|
| 裸身穿 gambeson | ~3-5 kg | 轻微降低体力回复 |
| gambeson + mail hauberk | ~18-22 kg | 明显体力惩罚、移速减 |
| 全副板甲（含内衬+mail）| ~30-40 kg | 走路掉体力、必须训练才能习惯 |
| 只穿部分板甲（如仅有胸甲）| ~15-25 kg | 权衡防护 vs 灵活性的战术选择 |

**关键机制**：穿板甲需要"习惯"——没受过训练的人穿上后近战极笨拙（大幅降低命中/闪避），需要类似原版 CDDA 的"穿戴技能/熟练度"系统或力量门槛。

**耐力系统**（后续策划案展开）：盔甲重量直接关联耐力消耗，重甲打持久战被拖死是真实的中世纪战斗结果。

## 七、CDDA 材料体系与中世纪盔甲映射

> 调研日期：2026-05-06
> 源文件：`data/json/materials.json`（103KB，60+ 种材料）
> 新增材料：`data/mods/Medieval/materials.json`（3 种新材料）

### 7.1 stab 抗性引擎支持确认

| 问题 | 结论 |
|------|------|
| material 层是否支持 `stab` resist？ | **支持。** 引擎通过 `load_resistances_instance(jo)` 读取 "resist" JSON 对象中的所有键值对（[material.cpp:87-88](E:\Cataclysm-Medieval\src\material.cpp:88)） |
| stab 是否为已注册 damage_type？ | **是。** `data/json/damage_types.json` 中定义为 `"id": "stab"`, physical=true, 由 cut 派生的近战穿刺类型 |
| stab 是否 `material_required`？ | **否。** 不像 bash/cut/bullet/acid/heat 那样强制要求。stab 有 `derived_from: ["cut", 0.8]`（仅对 monster 生效） |
| 原版已有 stab 材料？ | **是。** `kevlar` 定义了 `"stab": 5`，`leather`/`bone` 等未显式定义但可以添加 |

**结论**：在 material 的 `resist` 中添加 `"stab": N` 会被引擎正常读取并在护甲计算中使用。中世纪 mod 可以自由为所有材料定义 stab 抗性，实现"锁子甲怕穿刺"等差异化防护。

### 7.3 新增材料定义

为填补上述缺口，在 `data/mods/Medieval/materials.json` 中新增以下 3 种材料：

| ID | 名称 | bash | cut | stab | bullet | repair | 密度 | 对应设计层 |
|----|------|------|-----|------|--------|--------|------|-----------|
| `linen` | Linen（亚麻） | 1 | 1 | 1 | 1 | 1 | 1.5 | 第一层：内衣/衬衣 |
| `linen_quilted` | Quilted Linen | 2.5 | 2 | 1.5 | 1.5 | 1 | 1.5 | **第二层：gambeson 主材料** |
| `hardened_leather` | Cuir Bouilli | 3 | 5 | 3 | 2 | 4 | 1.2 | 第二~三层：硬化皮甲 |

**设计逻辑**：
- `linen_quilted` 的 bash 防御(2.5)高于 `cotton_quilted`(2)和`wool_quilted`(2)——亚麻纤维天然更强韧，多层绗缝后抗钝击缓冲更佳
- `linen_quilted` 的 stab 防御(1.5)偏低——布料对箭矢穿刺防护有限，符合"弓箭穿 gambeson"的历史事实
- `hardened_leather` 的 cut(5) 接近 `bronze`(5)，但 bash(3) 低于任何金属——正确反映了硬化皮"防割不防砸"的特性
- 所有新增材料均定义了 stab 抗性，可直接参与穿刺伤害计算

### 7.4 材质→中世纪盔甲映射总表

```
盔甲层级          CDDA 材料                      实际盔甲                    阶层
────────────────────────────────────────────────────────────────────────────
第一层(内衣)      linen                  ←→     亚麻衬衫/braies             全阶层
                 cotton / wool          ←→     棉/羊毛内衣（冬季）

第二层(垫层)      linen_quilted         ←→     Gambeson / Aketon           全阶层（核心独立盔甲）
                 cotton_quilted         ←→     棉质武装衣
                 wool_quilted           ←→     羊毛武装衣

第二~三层(轻甲)   leather               ←→     普通皮甲                    民兵/征召兵
                 hardened_leather      ←→     Cuir Bouilli（硬化皮甲）    轻骑兵/职业步兵

第三层(锁子甲)    budget_steel_chain    ←→     劣质铁环锁子甲              土匪
                 lc_steel_chain        ←→     熟铁锁子甲(Hauberk)         职业兵起（主流）
                 mc_steel_chain        ←→     优质锻钢锁子甲               骑士/重装兵
                 qt_steel_chain        ←→     淬火钢环锁子甲               贵族（罕见）

第四层(板甲)      lc_steel              ←→     熟铁板(Coat of Plates早期)  骑士
                 mc_steel              ←→     中碳钢板甲(14世纪末主流)     骑士/军官
                 hc_steel              ←→     高碳钢板甲                   精英重装兵
                 ch_steel              ←→     渗碳板甲(外硬内韧)           高级骑士
                 qt_steel              ←→     淬火回火板甲                 领主/王室

盾牌             wood                  ←→     木制盾牌                    全阶层
                 mc_steel              ←→     钢制盾牌（罕见）             贵族
```

**叠加规则**：gambeson (linen_quilted) + mail (lc_steel_chain) + plate (mc_steel) 三层同穿 = 真正的铁罐头。引擎会自动累加各材料层的 resist 值。

**维修难度梯度**：linen(1) → leather(3) → lc_steel(3) → mc_steel(4) → hc_steel(5) → qt_steel(7)，对应从"任何农民都能缝补"到"只有大师铁匠才能修复"的递进。
