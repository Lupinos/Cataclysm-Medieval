# 策划案 007：冒险者工会

## 设计目标

在 Mod 中建立**单一冒险者工会**作为可选的主线任务分发中枢，类似于原版 CDDA 的避难中心（Refugee Center），但不强制玩家参与。提供声望/等级成长、任务接取、基础服务，作为玩家在中世纪世界中长期目标感的锚点。

---

## 一、定位与原则

### 1.1 不是"任务贩售机"

工会出问题就是变成"接任务→交任务→领钱"的机械循环。设计底线：

- **任务有后果**：完成/失败的任务会改变世界（生成/移除 NPC、建筑、刷新）
- **人与人关系**：工会 NPC 记住你的行为，态度随你的选择变化
- **可选性**：玩家可以完全不管工会，靠狩猎/农耕/贸易活一辈子

### 1.2 单一工会，统一后端

```
         ┌── 冒险者工会（唯一 faction）──┐
         │  声望：统一                     │
         │  等级：统一                     │
         │  货币："工会令"                 │
         └────────────────────────────────┘
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
    北境分会站      王都总会站      港口分会站
    (任务偏向：     (任务偏向：     (任务偏向：
     剿匪/猎兽)     护卫/阴谋)     走私/海怪)
    不同 NPC       不同 NPC        不同 NPC
```

- 所有分会写入**同一个 faction**，声望和等级全地图共享
- 分会只是不同的 `mapgen` + `npc_class` + 本地任务表
- 技术上简单（一套数据），叙事上丰富（多个地点）

## 二、工会物理层 — 驻地设计

### 2.1 核心设施

```
┌──────────────────────────────────────────┐
│          冒险者工会驻地（24×24）           │
│                                           │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ 任务板  │  │ 酒馆/大厅│  │ 工会上层 │   │
│  │(告示栏) │  │(对话NPC) │  │(高级区域)│   │
│  └─────────┘  └─────────┘  └─────────┘   │
│                                           │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ 工会仓库│  │ 账房    │  │ 训练场  │   │
│  │(安全存储)│  │(兑换报酬)│  │(技能训练)│   │
│  └─────────┘  └─────────┘  └─────────┘   │
│                                           │
│  ┌─────────┐  ┌─────────┐                │
│  │ 马厩    │  │ 宿舍    │  (低等级不可用) │
│  │(坐骑租赁)│  │(免费住宿)│                │
│  └─────────┘  └─────────┘                │
└──────────────────────────────────────────┘
```

### 2.2 分级驻地

| 驻地等级 | 出现位置 | 设施 | 任务池规模 |
|----------|----------|------|-----------|
| 分会站 | 村庄级聚落 | 任务板 + 1 NPC + 基础仓库 | 3~5 个 |
| 总会站 | 集镇/城市 | 全套设施 + 5~8 NPC | 8~15 个 |
| 大本营 | 唯一（首都级别） | 全部 + 工会长 + 传奇任务 | 15+ 个 |

### 2.3 CDDA 实现

| 工会元素 | 实现方式 |
|----------|----------|
| 驻地建筑 | `mapgen` + `overmap_terrain`（`medieval-json-mapgen`） |
| 驻地 NPC | `npc` 实例 + `place_npcs` 放置到地图 |
| 任务板 | 特殊家具 + 可交互 talk_topic 入口 |
| 仓库 | mapgen 中的不刷新容器 |
| 马厩 | 生成坐骑 NPC 的特殊 mapgen |

## 三、声望与等级体系

### 3.1 等级阶梯

| 等级 | 称号 | 累积声望需求 | 解锁 |
|------|------|-------------|------|
| 0 | 无等级 | 0 | 基础任务板、基础仓库 |
| 1 | 铜级 | 100 | T1 任务、免费住宿 |
| 2 | 银级 | 300 | T2 任务、装备商店解锁 |
| 3 | 金级 | 600 | T2 高级任务、训练场 |
| 4 | 秘银级 | 1200 | T3 任务、马厩租赁 |
| 5 | 精金级 | 2500 | T3 传奇任务、随从招募 |

> 称号名称为暂定占位，后续可改为更写实的称谓（如学徒→熟手→大师→长老）。

### 3.2 声望获取

| 行为 | 声望 |
|------|------|
| 完成 T1 任务 | +10~20 |
| 完成 T2 任务 | +25~50 |
| 完成 T3 任务 | +60~120 |
| 击杀工会悬赏目标（额外） | +5~30 |
| 任务失败 | -5~15 |
| 背叛工会（攻击工会 NPC 等） | -大幅度 |

### 3.3 CDDA 实现

- 声望直接用 `faction` 的 `likes_u` / `respects_u` 值
- 等级通过 `u_add_var` 存储，用 `u_has_var` 条件检查
- 任务奖励中的声望增减通过 `mission_definition.end` 的 effect 实现

## 四、任务体系

### 4.1 三层任务池

| 层级 | 来源 | 难度 | 任务类型示例 |
|------|------|------|-------------|
| **T1 告示板** | 地方百姓 | 低 | 驱赶狼群、寻回失物、送信、采集药材 |
| **T2 工会委托** | 商人/贵族/教会 | 中 | 护送商队、调查失踪、剿匪、猎杀野兽 |
| **T3 紧急征召** | 领主/国王 | 高 | 守城支援、猎杀巨兽、追捕逃犯、遗迹清剿 |

### 4.2 任务设计模板

每个任务 = 一个 `mission_definition`，按此模板展开：

```
任务 ID：MISSION_MEDIEVAL_GUILD_[类型]_[编号]

基础信息：
  ├── name / description     → 任务名称和描述
  ├── goal                   → MGOAL_KILL_MONSTER / MGOAL_FIND_ITEM / MGOAL_GO_TO 等
  ├── difficulty             → 1~7
  └── value                  → 报酬

任务启动 (start)：
  ├── assign_mission_target  → 在地图上标出目标位置
  ├── update_mapgen          → 动态生成目标NPC/怪物/物品
  └── u_message              → 任务日志提示

任务完成 (end)：
  ├── u_adjust_var           → 增加声望变量
  ├── u_spawn_item           → 发放物品奖励
  └── talk_topic             → 触发 NPC 完成对话

任务链 (followup)：
  └── followup               → 完成后自动解锁下一任务
```

### 4.3 任务类型与 CDDA Goal 映射

| 任务类型 | CDDA Goal | 说明 |
|----------|-----------|------|
| 驱逐野兽 | `MGOAL_KILL_MONSTER_SPEC` | 击杀 N 只指定野生动物 |
| 赏金讨伐 | `MGOAL_KILL_MONSTER` | 击杀唯一命名目标 |
| 物资采集 | `MGOAL_FIND_ITEM` | 交付指定物品 |
| 物资批量 | `MGOAL_FIND_ITEM_GROUP` | 交付组内任意物品×N |
| 送信/传话 | `MGOAL_TALK_TO_NPC` | 与远方 NPC 对话 |
| 寻人 | `MGOAL_FIND_NPC` | 定位失踪 NPC |
| 护送 | `MGOAL_GO_TO` | 到达指定地点（与 NPC 同行） |
| 侦察 | `MGOAL_FIND_MONSTER` | 发现怪物巢穴位置 |
| 清剿据点 | `MGOAL_CONDITION` | 自定义：清除区域内所有敌对 |

### 4.4 任务刷新机制

```
┌─────────────────────────────────────────────────────────┐
│  EOC 定期轮询（每 N 天）                                 │
│    │                                                     │
│    ├→ 检查玩家等级/声望 → 决定可用任务层                  │
│    ├→ 检查玩家位置 → 决定任务目标与哪个分会相关            │
│    ├→ 检查当前已接任务数 → 上限控制                       │
│    └→ offer_mission → 任务进入可用池                      │
│                                                          │
│  任务板交互时：                                           │
│    ├→ talk_topic → TALK_MISSION_LIST                     │
│    └→ 列出当前可用任务（按等级筛选）                      │
└─────────────────────────────────────────────────────────┘
```

## 五、NPC 体系

### 5.1 工会 NPC 类型

| NPC 角色 | npc_class | 职责 | 数量要求 |
|----------|-----------|------|----------|
| 工会长 | `NC_GUILD_MASTER` | 发放传奇任务、晋升仪式 | 每个总会 1 人 |
| 分会管事 | `NC_GUILD_STEWARD` | 管理本地任务板、兑换报酬 | 每个分会 1 人 |
| 账房 | `NC_GUILD_PURSER` | 报酬兑换、装备买卖 | 总会 1 人 |
| 训练官 | `NC_GUILD_TRAINER` | 技能训练服务 | 总会 1~2 人 |
| 马倌 | `NC_GUILD_HOSTLER` | 马匹租赁/寄养 | 总会 1 人 |
| 守卫 | `NC_GUILD_GUARD` | 驻地安保 | 2~4 人 |
| 酒保/厨子 | `NC_GUILD_TAVERNER` | 饮食贩卖、闲聊（情报） | 1 人 |
| 随从候选人 | `NC_GUILD_RECRUIT` | 可招募的冒险者 | 随等级解锁 |

### 5.2 CDDA 实现

```
npc_class (技能/属性/装备模板)
    │
    ├→ NC_GUILD_MASTER    → 高 Speech, Literacy, 中等战斗技能
    ├→ NC_GUILD_STEWARD   → 高 Bartering, Speech
    ├→ NC_GUILD_PURSER    → 高 Bartering, 商人模式
    ├→ NC_GUILD_TRAINER   → 高战斗技能, 训练对话
    ├→ NC_GUILD_HOSTLER   → 高 Riding, Survival
    ├→ NC_GUILD_GUARD     → 中高战斗技能, 驻守 AI
    ├→ NC_GUILD_TAVERNER  → 高 Cooking, Speech
    └→ NC_GUILD_RECRUIT   → 随机战斗职业模板（从 profession 池抽）
```

装备通过命名约定分配：`NC_GUILD_GUARD_worn`、`NC_GUILD_GUARD_weapon` 等。

## 六、服务层

### 6.1 服务总览

| 服务 | 功能 | 解锁等级 | CDDA 实现 |
|------|------|----------|-----------|
| 任务发布 | 接取/交付任务 | 0 | talk_topic + mission_definition |
| 基础仓库 | 小容量安全存储 | 0 | mapgen 不刷新容器 |
| 免费住宿 | 工会宿舍睡觉 | 1 | mapgen 床位 |
| 装备商店 | 购买武器/盔甲 | 2 | `shopkeeper_item_group` |
| 技能训练 | 付费提升技能 | 3 | NPC 训练对话 |
| 马匹租赁 | 租用坐骑 | 4 | 生成临时坐骑 NPC |
| 大容量仓库 | 更大存储空间 | 4 | 更大容器 |
| 随从招募 | 招募冒险同伴 | 5 | `MGOAL_RECRUIT_NPC_CLASS` |
| 情报交易 | 揭示 map 区域 | 3+ | EOC `reveal_map` |

### 6.2 训练系统

| 可训练技能 | 训练官 | 上限 | 费用 |
|-----------|--------|------|------|
| Bashing / Cutting / Piercing | 训练官 | 当前等级+2 | 按等级递增 |
| Dodge | 训练官 | 当前等级+1 | 按等级递增 |
| Archery | 训练官（远程专精） | 当前等级+2 | 按等级递增 |
| Survival | 猎人随从 | 3 | 固定 |
| First Aid | 草药师/修士 | 3 | 固定 |

### 6.3 马匹租赁

- 按天计费，从工会声望中扣
- 马有随机品质（老马~战马），高等级解锁好马
- 马会死、需要饲料，不是永久资产（只有流浪骑士开局直接拥有马）
- 租来的马在死亡或时间到期后从世界中移除

## 七、与现有系统的接口

```
冒险者工会
    ├── 职业体系 (design05)     → 某些出身开局与工会有初始关系
    │                              （溃兵被工会通缉、流浪骑士自动铜级）
    ├── 武器/盔甲 (design02/04) → 工会商店商品池 (item_group)
    ├── 日常衣物 (design03)     → 工会守卫/职员着装
    ├── 敌人体系 (design08)     → 讨伐目标由敌人系统提供
    ├── 聚落 (design06)         → 工会建筑作为聚落的一部分
    ├── 世界观 (design01)       → 工会在三重崩塌中的角色
    └── 制作/经济               → 工会令可兑换稀有材料
```

## 八、初版 MVP 范围

| 功能 | MVP | 扩展 | 深度 |
|------|-----|------|------|
| 驻地 | 1 个总会站（24×24 mapgen） | 多城镇分会网络 | 分级驻地 |

| 声望 | 0~3 级 | 0~5 级 | 分支声望（在不同城镇有不同声誉） |
| 服务 | 任务板 + 基础仓库 | 完整服务层 | 马匹租赁 |

## 九、待定议题

1. **工会名称**：需要一个有中世纪味但不俗套的中文名（"冒险者工会"太直白）
2. **工会令（货币）**：是否需要独立货币？还是直接用银币？独立货币的好处是控制经济
3. **工会长角色**：是否作为后期关键 NPC（可能涉及主线剧情）
4. **跨分会任务**：T3 任务是否需要玩家在多个分会之间旅行完成？
5. **分会网络规模**：初版在世界中放置几个分会站？
