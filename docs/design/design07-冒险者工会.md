# 策划案 007：冒险者工会

## 设计目标

在 Mod 中建立**单一冒险者工会**作为可选的主线任务分发中枢，类似于原版 CDDA 的避难中心（Refugee Center），但不强制玩家参与。提供声望/等级成长、任务接取、基础服务，作为玩家在中世纪世界中长期目标感的锚点。

---

## 一、定位与原则

### 1.1 不是"任务贩售机"

工会出问题就是变成"接任务→交任务→领钱"的机械循环。设计底线：

- **任务有后果**：完成/失败的任务会改变世界（生成/移除 NPC、建筑、刷新）
- **人与人关系**：工会 NPC 记住你的行为，态度随你的选择变化
- **可选性**：玩家可以完全不管工会，靠狩猎/农耕/贸易活一辈子

### 1.2 单一工会，统一后端

```
         ┌── 冒险者工会（唯一 faction）──┐
         │  声望：统一                     │
         │  等级：统一                     │
         │  货币："工会令"                 │
         └────────────────────────────────┘
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
    北境分会站      王都总会站      港口分会站
    (任务偏向：     (任务偏向：     (任务偏向：
     剿匪/猎兽)     护卫/阴谋)     走私/海怪)
    不同 NPC       不同 NPC        不同 NPC
```

- 所有分会写入**同一个 faction**，声望和等级全地图共享
- 分会使用各自驻地、工作人员与本地任务，归属统一工会。
- 技术上简单（一套数据），叙事上丰富（多个地点）

## 二、工会物理层 — 驻地设计

### 2.1 核心设施

```
┌──────────────────────────────────────────┐
│          冒险者工会驻地（24×24）           │
│                                           │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ 任务板  │  │ 酒馆/大厅│  │ 工会上层 │   │
│  │(告示栏) │  │(对话NPC) │  │(高级区域)│   │
│  └─────────┘  └─────────┘  └─────────┘   │
│                                           │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ 工会仓库│  │ 账房    │  │ 训练场  │   │
│  │(安全存储)│  │(兑换报酬)│  │(技能训练)│   │
│  └─────────┘  └─────────┘  └─────────┘   │
│                                           │
│  ┌─────────┐  ┌─────────┐                │
│  │ 马厩    │  │ 宿舍    │  (低等级不可用) │
│  │(坐骑租赁)│  │(免费住宿)│                │
│  └─────────┘  └─────────┘                │
└──────────────────────────────────────────┘
```

### 2.2 分级驻地

| 驻地等级 | 出现位置 | 设施 | 任务池规模 |
|----------|----------|------|-----------|
| 分会站 | 村庄级聚落 | 任务板 + 1 NPC + 基础仓库 | 3~5 个 |
| 总会站 | 集镇/城市 | 全套设施 + 5~8 NPC | 8~15 个 |
| 大本营 | 唯一（首都级别） | 全部 + 工会长 + 传奇任务 | 15+ 个 |

### 3.1 等级阶梯

| 等级 | 称号 | 累积声望需求 | 解锁 |
|------|------|-------------|------|
| 0 | 无等级 | 0 | 基础任务板、基础仓库 |
| 1 | 铜级 | 100 | T1 任务、免费住宿 |
| 2 | 银级 | 300 | T2 任务、装备商店解锁 |
| 3 | 金级 | 600 | T2 高级任务、训练场 |
| 4 | 秘银级 | 1200 | T3 任务、马厩租赁 |
| 5 | 精金级 | 2500 | T3 传奇任务、随从招募 |

> 称号名称为暂定占位，后续可改为更写实的称谓（如学徒→熟手→大师→长老）。

### 3.2 声望获取

| 行为 | 声望 |
|------|------|
| 完成 T1 任务 | +10~20 |
| 完成 T2 任务 | +25~50 |
| 完成 T3 任务 | +60~120 |
| 击杀工会悬赏目标（额外） | +5~30 |
| 任务失败 | -5~15 |
| 背叛工会（攻击工会 NPC 等） | -大幅度 |

### 4.1 三层任务池

| 层级 | 来源 | 难度 | 任务类型示例 |
|------|------|------|-------------|
| **T1 告示板** | 地方百姓 | 低 | 驱赶狼群、寻回失物、送信、采集药材 |
| **T2 工会委托** | 商人/贵族/教会 | 中 | 护送商队、调查失踪、剿匪、猎杀野兽 |
| **T3 紧急征召** | 领主/国王 | 高 | 守城支援、猎杀巨兽、追捕逃犯、遗迹清剿 |

### 4.2 任务设计模板

每个任务明确委托人、目标、地点、危险程度、报酬、声望影响与失败后果。接受任务时给予足够线索，完成后由对应人员确认并交付奖励。连续任务需说明前后关系，解锁后允许玩家决定是否继续。

### 4.4 任务刷新机制

任务池随玩家声望、当地情况和时间更新，限制同时可接的任务数量。任务板列出当前可用委托及条件；刷新周期是玩法数值，不指定后台脚本或轮询方式。

## 五、NPC 体系

### 5.1 工会 NPC 类型

| NPC 角色 | 职责 | 数量要求 |
|----------|------|----------|
| 工会长 | 发放传奇任务、晋升仪式 | 每个总会 1 人 |
| 分会管事 | 管理本地任务板、兑换报酬 | 每个分会 1 人 |
| 账房 | 报酬兑换、装备买卖 | 总会 1 人 |
| 训练官 | 技能训练服务 | 总会 1~2 人 |
| 马倌 | 马匹租赁/寄养 | 总会 1 人 |
| 守卫 | 驻地安保 | 2~4 人 |
| 酒保/厨子 | 饮食贩卖、闲聊（情报） | 1 人 |
| 随从候选人 | 可招募的冒险者 | 随等级解锁 |

### 6.1 服务总览

| 服务 | 功能 | 解锁等级 |
|------|------|----------|
| 任务发布 | 接取/交付任务 | 0 |
| 基础仓库 | 小容量安全存储 | 0 |
| 免费住宿 | 工会宿舍睡觉 | 1 |
| 装备商店 | 购买武器/盔甲 | 2 |
| 技能训练 | 付费提升技能 | 3 |
| 马匹租赁 | 租用坐骑 | 4 |
| 大容量仓库 | 更大存储空间 | 4 |
| 随从招募 | 招募冒险同伴 | 5 |
| 情报交易 | 揭示 map 区域 | 3+ |

### 6.2 训练系统

| 可训练技能 | 训练官 | 上限 | 费用 |
|-----------|--------|------|------|
| Bashing / Cutting / Piercing | 训练官 | 当前等级+2 | 按等级递增 |
| Dodge | 训练官 | 当前等级+1 | 按等级递增 |
| Archery | 训练官（远程专精） | 当前等级+2 | 按等级递增 |
| Survival | 猎人随从 | 3 | 固定 |
| First Aid | 草药师/修士 | 3 | 固定 |

### 6.3 马匹租赁

- 按天计费，从工会声望中扣
- 马有随机品质（老马~战马），高等级解锁好马
- 马会死、需要饲料，不是永久资产（只有流浪骑士开局直接拥有马）
- 租来的马在死亡或时间到期后从世界中移除

## 八、初版 MVP 范围

| 功能 | MVP | 扩展 | 深度 |
|------|-----|------|------|
| 驻地 | 1 个总会站（单地块驻地） | 多城镇分会网络 | 分级驻地 |
| NPC | 管事 ×1 + 守卫 ×2 + 酒保 ×1 | 完整职能 NPC | 个人故事线 |
| 任务 | T1×5 + T2×3 | T1×15 + T2×10 + T3×5 | 任务链和世界影响 |
| 声望 | 0~3 级 | 0~5 级 | 分支声望（在不同城镇有不同声誉） |
| 服务 | 任务板 + 基础仓库 | 完整服务层 | 马匹租赁 |

## 九、待定议题

1. **工会名称**：需要一个有中世纪味但不俗套的中文名（"冒险者工会"太直白）
2. **工会令（货币）**：是否需要独立货币？还是直接用银币？独立货币的好处是控制经济
3. **工会长角色**：是否作为后期关键 NPC（可能涉及主线剧情）
4. **跨分会任务**：T3 任务是否需要玩家在多个分会之间旅行完成？
5. **分会网络规模**：初版在世界中放置几个分会站？
