# 远程伤害与弓弩平衡

## 设计目标

远程战斗应同时体现武器精度、射手训练、距离、命中部位和护甲。避免所有效果都集中在“极高爆头伤害或几乎无伤”的两端，也避免新手过早稳定击杀。

## 技能与装备

训练需要明显改善命中与有效射程。武器本身仍有精度上限，但不能完全淹没技能差异。专练弓术的角色应有清晰成长路径，不应因无关训练被不透明地削弱。

## 弓与弩

弓强调连续射击、力量与长期训练；弩强调准备成本、装填间隔和单次射击可靠性。二者应互补，不能只由同一项伤害数值决定优劣。

## 弹药与护甲

穿甲箭头与宽刃狩猎箭各有适用目标。伤害、穿甲、暴击与护甲覆盖共同决定结果。轻甲、锁甲与板甲应有可理解的战术差异。

## 待确认数值

旧研究提出提高武器本体精度、扩大技能差距、降低低技能近距离收益的方向；旧模拟器的具体百分比依赖当时公式，不作为重做后的已验证平衡结论。先以不同技能、距离和护甲的实际命中与击杀表现决定数值。
