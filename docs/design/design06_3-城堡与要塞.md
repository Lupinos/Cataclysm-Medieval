# 城堡与要塞

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

城堡兼具权力、居住与防御功能；要塞以控制交通、驻守与军事防御为主要选型方向。设防庄园、塔楼宅邸、领主城堡和驻军要塞分别列出。小型关隘堡或哨所未必构成独立聚居地，仍作为建筑群调查；堡外有持续居住的家庭和服务人员时，再辨认其附属聚居区。

## 二、历史原型

### Stokesay：设防宅邸

英格兰Stokesay大部分现存主体在1291年前完成，包含大厅、私人居住翼和塔楼。English Heritage明确区分其军事外观与抵挡正式围攻的能力。现存木构门楼建于1640–1641年，不能用于约1400年的建筑选型。[English Heritage建筑说明](https://www.english-heritage.org.uk/visit/places/stokesay-castle/history-and-stories/description/)

### Goodrich：领主城堡

Goodrich位于英格兰与威尔士边境附近，保留不同时期的城堡建筑，13世纪末家庭账目提供城堡生活原型。其主要历史用途包含贵族家庭生活，不能只保留城墙与兵器库而删去居住、厨房和供应空间。[English Heritage城堡史](https://www.english-heritage.org.uk/visit/places/goodrich-castle/history-and-stories/history/)

### Dartmouth：港口防御堡

Dartmouth于1388年开始建设的港防堡只在危险时使用，常设建筑很少；约一世纪后才加强为炮塔。它支持小型港防据点的方向，后期炮塔不纳入1388年原型。[English Heritage城堡史](https://production.english-heritage.org.uk/visit/places/dartmouth-castle/history/)

## 三、具体聚居地类型

| 类型 | 核心区别 | 优先建筑组合 |
|---|---|---|
| 设防庄园 Fortified Manor | 家庭经营与身份展示为主，有一定防护 | 大厅住宅、私室翼、厨房、经营附屋、院墙与入口 |
| 塔楼宅邸 Tower House | 以防御性塔楼容纳主要生活空间 | 多层塔楼、附属院落、厨房或服务附屋、储粮和畜养空间 |
| 领主城堡 Castle | 居住、统治和防御结合 | 主体住宅、大厅、礼拜堂、厨房、仓库、马厩、门楼与防御塔 |
| 驻军要塞 Fortress | 常驻军事力量与区域防御为主 | 驻军住所、指挥官住所、军需库、厨房、烤房、修理工坊与防御工事 |
| 关隘堡、桥头堡 Pass / Bridge Fort | 控制道路、桥梁或狭窄通道 | 门楼或塔楼、守军住所、储粮建筑、马厩及条件性的收费场所 |
| 港防堡 Coastal Fort | 守卫港口入口或水道 | 围墙、塔楼、值守与储备空间；小型临时驻守方案不强设完整兵营 |

塔楼宅邸、驻军要塞、关隘堡和桥头堡的具体基准期原型继续另选，不由Goodrich单一原型推定全部格局。

## 四、典型建筑目录

| 建筑或建筑组 | 主要空间与功能 | 适用条件 |
|---|---|---|
| 主塔、主堡 | 防御、储藏及可能的起居或大厅 | 并非每座城堡都有独立主塔，具体功能按原型分层核查 |
| 大厅建筑 | 宴饮、接待、家庭或管理活动 | 可独立，也可位于主塔或居住翼内 |
| 领主居住翼、指挥官住所 | 私人起居与办公 | 领主家庭与纯军事指挥用途分别选型 |
| 守军住所 | 卫兵、随从或驻军生活 | 可位于塔楼、门楼和附属房；独立兵营须有对应方案 |
| 礼拜堂 | 家庭或守军宗教活动 | 可独立或嵌于门楼及住宅建筑 |
| 厨房、烤房、酿酒房 | 炊事与日常供应 | 炉火、运输和与大厅的连接是调查重点 |
| 粮仓、食品库、酒窖 | 储粮与食物保存 | 酒窖可为地下或底层房间，不一律另建一栋 |
| 军需库、军械库 | 保存武器、防具及供应物资 | 可是受控库房；不默认摆满完整骑士装备 |
| 马厩、车棚、草料仓 | 坐骑与运输后勤 | 可在外院，大小依实际马匹及运输需求 |
| 铁匠铺、木工作坊 | 修理兵器、铁件、车辆及木结构 | 不等于同时具备采矿、炼铁和全套高级军械生产 |
| 管理房、账房、文书库 | 收租、账务与文书保存 | 可与住宅或大厅建筑合设 |
| 拘押室 | 临时或持续拘禁 | 不要求每堡都有大型地下监狱 |
| 门楼、侧防塔、城墙塔 | 控制入口、观察与侧防 | 内部可含值守、储物、居住或礼拜空间 |

配套设施：幕墙、壕沟、护城河、桥、吊桥、外堡、内院、水井、蓄水池、炉灶、厕所和条件性的训练空地。水壕、吊桥及外堡不在每种原型中同时出现；厕所可以嵌于墙体或塔楼。

## 五、空间关系与细查重点

分别调查入口防御、领主或指挥空间、守军生活、食物供应、马匹与运输。内院和外院可以承担不同功能，但不固定为每堡一套同样的分区。堡外住宅、商铺、旅店与工坊构成附属聚居区时，沿用城镇或村庄篇的建筑类型。

后续先细查主堡与大厅、居住翼、门楼、守军住所、厨房和仓储、马厩及工坊。基准期具体塔楼宅邸和关隘堡需补充原型，再确定其房间组合。
