# 修道院聚居地

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

收录修院核心建筑、其经营与服务院落，以及围绕宗教机构形成的常住聚居区。小型修院、大型修道院、修道院庄园和朝圣聚居地按组织功能分别调查；男修院、女修院及不同修会制度不能共用未经核查的一套生活平面。

## 二、历史原型

### Rievaulx：大型修道院及生产院落

英格兰Rievaulx的建筑说明列出教堂与回廊周围的生活建筑、取暖室、食堂、厨房和医护院。院墙内还有畜养、农业、生产、果园和园圃空间。可据此建立宗教核心、共同生活与经营附属区的关系。[English Heritage遗址说明](https://www.english-heritage.org.uk/visit/places/rievaulx-abbey/history-and-stories/history/description/)

15世纪末医护院被改作院长住宅，不能把这一后期形态直接用于约1400年。Historic England对部分遗迹的功能辨认也包含重新解释，说明“客舍”“工坊”等名称需逐栋核查。[Historic England遗址登记](https://historicengland.org.uk/listing/the-list/list-entry/1012065)

## 三、具体聚居地类型

| 类型 | 组织特点 | 优先建筑组合 |
|---|---|---|
| 小型修院 Small Religious House | 少量成员，生活空间可能合并 | 教堂或礼拜堂、住宿、食堂厨房、储物、少量经营附屋 |
| 大型修道院 Abbey | 宗教核心与共同生活、经营系统较完整 | 修院教堂、回廊翼楼、宿舍、食堂、医护院、院长住所、客舍及外院 |
| 修道院庄园 Monastic Grange | 以农业经营和收益供应修院 | 管事或经营人员住所、谷仓、畜舍、仓储、磨坊及可能的礼拜堂 |
| 朝圣聚居地 Pilgrimage Settlement | 圣地接待与旅客服务推动常住人口聚集 | 圣地教堂、旅舍、施济建筑、店铺、马厩及居民住宅 |

后三种中的庄园和朝圣聚居地仍需具体基准期原型；Rievaulx用于大型修道院，不作为所有宗教机构的统一模板。

## 四、典型建筑目录

| 建筑或建筑组 | 功能与主要空间 | 出现条件 |
|---|---|---|
| 修院教堂 | 共同礼拜 | 中殿、唱诗席、侧廊等是内部空间，具体规模另核 |
| 回廊翼楼 | 将集会、阅读、起居与服务空间连接 | 回廊是交通与活动空间；章节室、取暖室可在翼楼内 |
| 宿舍楼、住宿翼 | 成员睡眠与生活 | 通铺、隔间与私人房间按年代、修会和具体改建核查 |
| 食堂、厨房及烤房 | 共同用餐和备膳 | 食堂与厨房可位于相邻翼楼，烤房可另设 |
| 院长或院长嬷嬷住所 | 机构负责人生活与接待 | 不把后期扩建豪宅直接视为基准期标准 |
| 医护院 | 病弱和年老成员照料 | 大型机构可有独立院落、厨房及礼拜空间 |
| 客舍 | 接待外来宾客 | 按身份与访问目的分区是候选，具体分法须核原型 |
| 门房、施济所 | 出入控制、发放救济与接触外界 | 可合设于入口建筑或附近，不把门房等同军事堡门 |
| 书籍保管与抄写空间 | 保存、阅读和制作文本 | 可在回廊、壁柜、房间或独立建筑中；不默认每院都有独立大图书馆 |
| 酿酒房、磨坊、仓库、谷仓 | 饮食供应及经营 | 与周围土地、交通和水源联系 |
| 畜舍、马厩、车棚 | 生产与运输 | 生活核心以外的院落选型 |
| 铁匠坊、木作坊、其他生产作坊 | 维护与经营 | 产业依具体修院核定，不给每院附加全行业工坊 |
| 朝圣旅舍、施济医院、售卖店铺 | 圣地接待与居民服务 | 属朝圣聚居地配套，可在修院院墙外 |

配套设施：墓园、庭园、药草园、菜园、果园、鱼塘、水渠、排水设施、院墙及院门。药草园与医护院相关但不是一座药房；鱼塘也不等于所有修院都经营渔村。

## 五、空间关系与细查重点

区分成员日常生活区、接待外来者的空间及经营院落。礼拜、用餐、睡眠、照料病人、储粮与处理废水各有空间关系；低魔设定不改变这些基础需求。

后续细查修院教堂、回廊翼楼、宿舍食堂、医护院、客舍和经营外院。宗教建筑与圣物的游戏效果不在本轮目录中预定。
