# 策划案 003：日常衣物与随身装备

## 设计目标

为02盔甲与04武器的全部地域路线提供可穿、可携行的衣物组合。基础内衣、鞋、腰带和包袋共用；只在裁剪、覆盖、材料结构或使用方式形成实际差别时增加装备。地域决定常见搭配和外观，不限制角色混穿。

历史只提供结构参考。表内材料、厚薄与组合为游戏方案，具体防护服归02；普通夹衣、袍裤与斗篷不会因名称含“骑兵”或“武装”自动成为护甲。

## 一、物料体系

| 材料 | 主要用途 | 设计取舍 |
|---|---|---|
| 亚麻 | 衬衣、内裤、轻外衣、里布、包袋 | 薄款透气、吸汗；厚织与多层款可增加保暖和负担，不统一视为不保暖 |
| 棉 | 衬衣、缠头、袍服、里布与填充 | 西亚及草原联系地区的普通可选纤维，不统一限定为奢侈品；填充与机织布分别记录 |
| 羊毛 | 外衣、长袜、裤、帽、斗篷和披布 | 薄织、厚织、毡缩分别选用；厚款暖、抗风较好，湿后仍有负担 |
| 皮革 | 鞋靴、腰带、手套、包袋、弓袋与箭囊 | 鞋面、鞋底、柔软包皮与硬皮保护件分别用料；硬皮战斗护具归02_3 |
| 毛皮 | 寒地外衣、斗篷、帽沿与里衬 | 寒地保暖变体，不为各地域重建同功能皮草衣物 |
| 丝与丝绒面料 | 袍服、罩衣、饰边与高价服装变体 | 影响价格、外观、重量和维护；不自动提高战斗防护。绒面材料说明纤维，不默认都是棉 |
| 草、麻绳、涂油织物 | 草帽、绳带、防雨外层 | 涂油层抗雨但排湿较差；防雨效果取决于涂层与覆盖，不设整类绝对免水 |

结构参考：[Met高加索Kaftan](https://www.metmuseum.org/art/collection/search/327518)提供前开长袍的裁剪与面里关系；[Aga Khan Museum AKM677](https://collections.agakhanmuseum.org/collection/artifact/robe-AKM677)提供收腰、展开衣摆的骑乘袍轮廓；[V&A馆藏Kaftan说明](https://clothing.museumwnf.org/database-item/mwnf3/objects/ISL/uk/Mus02/34/en/)提供丝面及饰边变体；[苏格兰服饰研究](https://www.pure.ed.ac.uk/ws/files/24383310/Scottish_Male_Dress.pdf)提供披布多用途穿法。以下普通面料、尺码与厚度由游戏设计选择，不要求复制装饰实物。

## 二、衣物逐部位详表

表中“一件”指一个整体穿脱/携带单位；左右成对物品注明按对使用。面料厚度起点集中在第四章，具体装备可按季节选薄厚变体。

### 2.1 头部

| 物品 | 材料与覆盖 | 穿戴单位、层位与用途 | 共用与变体 |
|---|---|---|---|
| 贴身布帽（Coif） | 亚麻或棉；头顶、侧后头，可带耳侧片 | 一件，贴身层；吸汗与隔开金属内衬 | 所有路线共用；不是金属盔或绗缝头甲 |
| 草帽（Straw Hat） | 草编；头顶与宽檐遮阳 | 一件，外套层；田间与出行 | 西欧、南欧及其他农民共用，不因地区另建同款 |
| 毡帽/软圆帽（Felt Cap / Bonnet） | 羊毛毡或厚毛织；头顶、侧头 | 一件，普通层；保暖与日常穿戴 | 北方、东欧软帽沿用；苏格兰圆帽为轮廓变体，不新增防护帽类别 |
| 羊毛兜帽（Wool Hood） | 羊毛；头、颈与肩上 | 一件，外套层；挡风保暖 | 英法、中欧、北方共用，毛皮里衬属寒地变体 |
| 带尾兜帽（Chaperon） | 羊毛；头颈，长尾可卷起 | 一件，外套层；城镇服饰与防风 | 与普通兜帽按结构选择，卷戴不额外生成另一顶帽 |
| 皮贴帽（Leather Coif） | 软皮；头顶与耳侧 | 一件，普通层；耐磨挡风 | 猎人和作业者共用，不按硬皮盔赋防护 |
| 缠头布（Headwrap / Turban） | 棉或亚麻长布；头顶、额与侧头 | 一件，普通层；遮阳吸汗；可展开但不另生成一块物品 | 西亚、草原联系地区共用；薄内缠/较大外缠为厚度变体；不与金属包巾形盔混为一物 |

普通帽与金属盔并非都需要同时穿。金属盔默认使用其内含衬里或一件薄贴身布帽；厚毡帽、外缠头和宽檐草帽不强制塞进盔内。

### 2.2 躯干——内衣层

| 物品 | 材料与覆盖 | 穿戴单位与用途 | 共用边界 |
|---|---|---|---|
| 轻布衬衫（Linen/Cotton Shirt） | 亚麻或棉；胸腹背与双臂 | 一件，贴身层；吸汗、减摩擦 | 原亚麻衬衫作为材质变体；西亚棉衬衣不另建同裁剪物品 |

| 布内裤（Braies / Drawers） | 亚麻或棉；腰臀与上腿 | 一件，贴身层 | 欧洲短款与袍裤内短裤用同类裁剪变体；不在长袜外强制再穿一条 |

|---|---|---|---|
| 束腰外衣（Tunic） | 羊毛、亚麻或棉；胸背、肩臂与髋，长款可至膝 | 一件，普通层；日常主衣 | 羊毛/亚麻材质变体共用；北方长衫沿用较长衣摆，不额外做“北欧Tunic” |
| 紧身夹衣（Doublet） | 羊毛/轻布面，亚麻或棉里；躯干双臂 | 一件，普通层；合体穿着，可系挂长袜 | 德意志膨袖、意大利合体、伊比利亚简洁饰面归裁剪/外观变体；无填充的普通夹衣不等于02武装衣 |
| 束腰长裙（Kirtle） | 羊毛/亚麻/棉；躯干、双臂与腿 | 一件，普通层；日常长衣 | 服饰覆盖，不按腿甲算；与同覆盖长袍按穿法选择 |
| 前开长袍（Kaftan） | 棉/羊毛/亚麻面里；胸背、双臂和大腿至小腿上段 | 一件，普通层；前襟开合、腰带收束、两侧开衩 | 东欧、安纳托利亚与伊朗方向共用主体；窄/宽袖、素面/丝面为变体，不按国家复制三件 |

| 麻布工作围裙（Work Apron） | 粗亚麻或棉布；胸腹正面和大腿前 | 一件，外套层；防污磨耗 | 所有地区工匠/农人共用 |
| 皮工作围裙（Leather Apron） | 皮革；胸腹正面和大腿前 | 一件，外套层；作业防溅与耐磨 | 铁匠、屠夫等共用；不等于免火或整圈皮甲 |

日常主衣和02的甲下衣按用途选择，不要求先穿齐衬衫、Tunic、Doublet、袍服才允许穿甲。衣袖和裙摆内含，不单独建立同衣的袖子/裙摆物品。

| 物品 | 材料与覆盖 | 穿戴单位与层位 | 用途与共用 |
|---|---|---|---|
| 羊毛长袜（Hose） | 羊毛或较薄机织布；腿，可连足 | 分离式按一对，普通层；连裆式为一件 | 与夹衣、短上衣配套；分离、连裆及连足/无足归结构变体，原三种hose不再算三层必须叠穿 |

| 束口骑乘裤（Riding Trousers / Shalvar方案） | 棉、羊毛或亚麻；臀腿，宽裆上腿、收窄裤脚 | 一件，普通层 | 西亚与草原共用；蹲骑空间更大，用料和靴内堆叠与直筒裤不同，不因称波斯/土耳其再拆件 |

## 三、腰带与随身物品

| 物品 | 材料/结构 | 独立件与组合关系 | 使用边界 |
|---|---|---|---|
| 皮腰带（Leather Belt） | 皮带与扣 | 一件；包袋与刀鞘另挂 | 所有地区共用；金属饰片为外观/重量变体 |
| 绳带（Rope Belt） | 麻绳或棉绳 | 一件 | 低成本系结，不等于同容量背包 |
| 布腰巾（Sash） | 棉、亚麻、羊毛或丝长布 | 一件，腰部围束 | 西亚、草原袍服共用；内挂武器仍需可靠挂带，不凭腰巾获得无限挂载 |
| 腰包（Belt Pouch） | 皮或织物小袋、闭合口 | 一件；挂腰带 | 钱币、小工具等共用储物 |
| 斜挎包（Scrip / Shoulder Bag） | 布或皮，肩带 | 一件 | 旅行与劳动，不重复为朝圣者/商人/牧民造同袋 |
| 水囊（Waterskin） | 缝皮囊与塞口 | 一件 | 共用饮水容器 |
| 火绒袋（Tinder Pouch） | 小皮袋 | 一件；火镰、火石和火绒是内容物 | 不用袋子名称代替自动生火功能 |
| 木杯（Wooden Cup） | 木 | 一件工具，另挂 | 共用饮具 |
| 刀剑鞘与挂带（Scabbard and Suspension） | 木芯/皮包覆或软皮，挂带 | 与武器分开的携行附件；不重复生成武器 | 直刃/曲刃、长短与鞘口按武器匹配；Kilij和Shamshir不强塞直剑鞘，通用原理仍共用 |
| 弓袋（Bow Case） | 皮或布包覆，弓形开口与挂带 | 一件，放一张匹配外形的弓 | 骑乘复合弓用短曲弓袋，长弓用长形携行套；尺寸变体共用类别 |
| 箭囊（Quiver） | 皮/木骨架/织物，敞口或带盖 | 一件，箭是内容物 | 胯侧、腰后等挂法为携行变体；不把一囊箭再算成另一把弓 |
| 弩矢盒（Bolt Case） | 木/硬皮或布包覆，较短加盖结构 | 一件，弩矢为内容物 | 与长箭囊按长度、开口和保护结构区分；上弦器仍是04工具附件 |

弓袋、箭囊和腰带组成携行组合但仍为独立物品。箭囊和弓袋可左右换挂，按角色用手与射法决定，不固定一个地域所有角色同一侧。投矛、投斧、飞刀用合适挂带或现有包袋，不因每种武器再建一套同功能背包。投石索收于腰包、弹丸放袋；弩用小型独立上弦器可腰挂，较大绞盘/齿轮上弦器以挂带或挎包携带；长柄武器通常持握、肩扛或外绑，不虚构能装任意长枪的普通鞘。

## 四、服装材料属性对照

以下为设计选料范围，不是馆藏测量；成衣层数和覆盖确定后再核算总重。mm指单层面料或皮革厚度；绗缝填充的自由厚度见02_4，不混用。

| 部位/构件 | 设计用料与厚度起点 | 对选型的影响 |
|---|---|---|
| 衬衣、长衬衣、内裤、贴帽 | 亚麻/棉单层约0.3–0.6mm | 轻薄贴身，保暖随层数和覆盖变化 |
| 缠头、腰巾 | 亚麻/棉约0.3–0.6mm，羊毛约0.6–1.0mm；绕层数单独算 | 多绕会增加厚度、热负担与用料，不等于同重量免费加强 |
| Tunic、裤、长袜 | 亚麻/棉约0.5–0.9mm；羊毛约0.8–1.5mm | 直筒、宽裆、长袜按剪裁量和关节余量区别 |
| Doublet、前开长袍、斜襟骑乘袍 | 面约0.6–1.2mm，里约0.3–0.6mm；冷地加厚面料 | 领袖、前襟、开衩、系结处局部加强；日常款不默认填成甲 |
| 斗篷、披肩、束腰披布 | 羊毛约1.0–2.0mm，寒地厚款可加里 | 长短与围裹面积会改变重量；披布肩腿共享同一幅材料 |
| 皮手套、帽、包袋 | 软皮约0.8–1.5mm；护腕皮约2–3mm | 柔软抓握与局部耐磨分别选择 |
| 鞋靴 | 鞋面约1.5–2.5mm，柔软靴筒约1.0–2.0mm，鞋底多层合计约4–6mm | 靴筒不是与鞋底同厚的硬皮；按行走和骑乘取舍 |
| 腰带与携行具 | 腰带皮约2.5–4mm；弓袋/箭囊皮壳约1.5–2.5mm，木骨架另记 | 支撑、外部占用和所装物重量一起考虑，不统一设无限容量 |

薄衣透气、厚衣保暖是选型方向；织密、涂层、风、潮湿和穿着层数会影响结果。羊毛、皮革和油布均不写成绝对不燃、绝对防雨。普通衣物的有限擦伤防护不替代02的专门护甲。

## 六、补丁与物品状态

补丁、磨损、破洞、潮湿和脏污是已有衣物的状态，不各自新增物品。地域衣型同样遵循此规则。修补材料按本体织物/皮革选择，不为每个地区新增等价针线工具。补丁可影响外观与性能，具体规则在实际实现时确定。

## 七、设计取舍与合并边界

1. 气候、活动与负重决定薄厚，地域不是固定防御或保暖加成。
2. 共享衬衣、内裤、Tunic、夹衣、鞋靴、手套、斗篷和基础包袋；有不同剪裁或使用结构才保留独立类。
3. 前开长袍与斜襟骑乘袍、直筒裤与束口骑乘裤、斗篷与束腰披布的差别写在覆盖和穿法，不只换名称。
4. 普通服饰、甲下衣和主甲是按需要选择的组合，不要求穿四五层普通衣服才能穿甲。
5. 弓袋、箭囊、弩矢盒与刀剑鞘属于独立携行附件；它们不附赠武器、弹药或防护。
6. 同一衣型的丝面、毛皮里衬、饰边、染色和帽檐变化优先作为变体。没有独立功能时不另建国家专属物品。
