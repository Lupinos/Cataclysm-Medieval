# 策划案 004_3：斧

父案：[武器体系](design04-武器.md)。

## 一、范围与物品单位

收录以斧刃为主的独立武器及工具斧候选。斧头、木柄、楔和固定件构成一把完整斧；髯部是刃形特征，不另算一件钩具。带完整顶刺及锤面等复合结构的步战兵器集中到[长柄分案](design04_5-枪矛与长柄兵器.md)。

## 二、历史原型与资料

### A1：Cleveland 1916.1601 战斧

可能斯堪的纳维亚，15世纪；钢与木，全长93.3cm、馆录blade尺寸18.7cm、重1.22kg。属于可明确识别的长柄战斧比较样本；馆录只给世纪，不能断言制造于1425年前。刃厚、斧头单独重量、柄是否原装、热处理均待核。[Cleveland馆录](https://www.clevelandart.org/art/1916.1601)

### A2：伦敦 A23339 战斧

斯堪的纳维亚相关，11世纪早期，铁；斧刃宽182mm、高173mm，馆录厚度29mm的具体测点待核。960mm柄明确为复原柄，不能作为出土原柄长度。此物是较早宽刃斧参照，并不证明约1400年仍普遍配发所谓“维京丹麦斧”。[伦敦馆录](https://www.londonmuseum.org.uk/collections/v/object-37979/battleaxe/)

### A3：工具斧资料边界

伦敦博物馆《Medieval Catalogue》设有战斧与工具章节，可作后续逐件选择锚点；目前只核到目录，不把尚未核读的插图编号当成已确认原型。[馆方图录书目及目录](https://books.google.com/books?id=kiFsuMPyOjkC)

### A4：Saint Louis 45:1919 骑兵斧

可能匈牙利或波兰，16世纪晚期至17世纪，钢与木，馆录名称Horseman’s Axe（Czekan或Czákan）。它可作骑兵斧的地域与用途参照，不能当作1400年骑兵制式斧。具体基准期样本和装柄仍待选。[Saint Louis馆录](https://www.slam.org/collection/objects/13209/)

### A5：Pitt Rivers 1884.21.53 巴迪什长斧资料

馆方将Berdiche／Bardiche介绍为东北欧以及土耳其、近东相关长柄斧类，提供独立于复合长戟的类型依据；本轮不从其概述推定这件藏品的精确定年与完整尺寸。[Pitt Rivers藏品与类型说明](https://web.prm.ox.ac.uk/weapons/index.php/tour-by-region/europe/europe/arms-and-armour-europe-153/)

## 四、构件与材料

| 分区 | 需记录内容 |
|---|---|
| 斧刃 | 刃线、刃宽、截面和刃厚渐变；钢刃与铁体有无锻接需证据 |
| 斧眼与颈部 | 柄孔形状、连接方向、头部固定；馆录最大厚度不等于刃口厚度 |
| 木柄 | 总长、截面、弯曲与握持区；木种与原装性分别核实 |
| 加固件 | 护条、包铁、楔或铆接，按实物说明；不为凑齐结构添加 |

A1的1.22kg不支持“战斧天然数公斤重”的统一设定；A2只存历史斧头与复原柄信息，不推定原始整斧重量。材质变化与装饰优先为同形制变体。

## 五、使用定位与取舍

战斗斧的刃形、柄长和配重应服务于挥击与回收；工具斧需要保留木作用途，其厚楔形刃不能自动等同于更好的战斗斧。钩挂能力取决于具体刃下空间、方向和动作，不因“髯斧”名称就保证拖倒目标。

本篇不将所有双手斧写成高破甲重武器。是否伤及甲下目标需结合打击面和目标结构，不以斧的总重直接给出固定穿甲结论。
