# 独立建筑与野外地点

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

本篇收录可以在城镇、村庄等聚居区以外独立出现的建筑、院落和小型建筑群。参照CDDA原版特殊地点的丰富程度，建立本世界的详细地点目录；“特殊”表示可单独作为一个地点辨认，不表示一定稀有、危险或带有超自然内容。

独立存在是空间上的独立，不等于经济自给或没有归属。磨坊可以服务附近数村，哨塔可以由远处城堡供应，庄园和修院也可以拥有远离本院的仓储、农场与生产设施。建筑群内有一家人、少量雇工或守军，不自动成为另一种村庄；发展为具有多户日常生活和公共服务的常住社区时，转入相应聚居地分案。

沿用约1375–1425年的欧洲参照。以下是游戏建筑选型目录，原版地点仅支持独立地点的组织思路；本篇新增候选的具体历史建筑原型、地域和年代仍需逐项核查，不能把现代地点改名后视为历史复原。已有分案中的城堡、修院、农庄等在此只说明独立存在的组合，建筑本体沿用原分类。

## 三、详细建筑与院落目录

每行表示一个可单独选型的建筑或院落方向。主要空间是后续调查的功能提纲，独立附屋与内部房间的最终划分以具体原型为准；不要求每处地点包含表内列出的全部附属设施。

### 3.1 独居住宅与乡间宅邸

| 建筑类型 | 选址与使用者 | 主要空间与附属设施 | 与相近类型的区别 |
|---|---|---|---|
| 林间住宅 Woodland Cottage | 林缘或林中道路旁的常住家庭 | 起居炊事、睡眠、储物、柴棚、菜园 | 森林中的普通住所；职业用途另选，不因木墙另建一种类型 |
| 猎人小屋 Hunter’s Cottage | 猎场附近、有持续狩猎活动的区域 | 住所、猎具储藏、猎物处理棚、皮张晾放处 | 以长期居住和猎物处理为主，区别于临时猎棚 |
| 渔人小屋 Fisher’s Cottage | 可捕鱼的河岸、湖岸或海岸 | 住所、网具棚、鱼货处理、简易靠船处 | 一户经营，与形成多户社区的渔村区分 |
| 林务看守住宅 Forester’s Lodge | 管理林地或猎场的通道附近 | 住所、工具库、管理储物、条件性的马厩与犬舍 | 与普通猎户的职责和服务对象不同，具体管理制度待核 |
| 乡间宅邸 Country House | 庄园土地、园圃或交通便利的乡野 | 大厅、私室、厨房、储藏、仆役住所、经营附屋 | 富裕家庭住宅，防御不是主要组织方式 |
| 设防庄园 Fortified Manor | 需要防护的乡间经营中心 | 大厅住宅、服务附屋、围院、可控制的入口 | 沿用城堡篇类型；不因有围墙就成为驻军要塞 |
| 塔楼宅邸 Tower House | 边境、山地或其他需要防护的地区 | 多层起居储藏、入口防护、附院、畜养与服务附屋 | 以塔楼整合生活与防护，具体地域原型待选 |
| 贵族猎庄 Hunting Lodge | 领主猎场或季节性狩猎区域 | 接待大厅、寝室、厨房、马厩、犬舍、随从住处 | 贵族狩猎接待院落，区别于猎人家庭小屋和军事据点 |

同一住宅的河边、湖边、山坡或湿地版本先作为选址变体；湿地住所的地基、通行与取水另核，不单凭环境名称增加重复房型。

|---|---|---|---|

| 育马场 Stud Farm | 大片牧地、有稳定购买或供养者 | 管事住宅、种马和母马厩、幼驹围场、饲料仓、修蹄作业处 | 与旅店寄马、普通农户养马的经营功能不同 |
| 季节性牧棚 Seasonal Herding Hut | 季节牧场、山地草场 | 牧人睡眠炊事、奶品处理、工具储物、临时畜栏 | 是季节住处，不必建设完整常住农庄 |

| 独立谷仓 Field Barn | 耕地或偏远经营地附近 | 收获物堆放、打谷或装卸、农具储物 | 需要实际生产与运输联系，不等于随机空置仓房 |
| 独立粮仓 Granary | 庄园、修院或其他经营者的储粮节点 | 干燥储粮、分仓、装卸与看守空间 | 与打谷谷仓区别；防鼠防潮形式随地域核查 |

| 鸽舍 Dovecote | 庄园经营地或其他有依据的乡野地点 | 饲养巢位、维护出入、清理空间 | 可独立成构筑物，不强配住宅；设置权利与地域另核 |

| 航标灯塔 Beacon Tower | 有实际航行需求的岬角、岛屿或岸段 | 标识塔体、看守住处、燃料与补给储藏 | 具体历史原型、灯火形式待核，不沿用原版现代灯塔设备 |

桥、渡口、道路营地和码头也可以没有房屋。此时保留为交通设施或临时地点，不为凑建筑数量额外添加旅店、税关或守屋。

### 3.6 宗教、救济与丧葬建筑

| 建筑类型 | 选址与使用者 | 主要空间与附属设施 | 出现条件与区别 |
|---|---|---|---|
| 路边礼拜堂 Wayside Chapel | 交通路线、偏远经营地或礼拜地点 | 礼拜、少量储物、条件性的守堂住处 | 与只有神龛的小型圣祠区别，不自动配完整教区建筑 |
| 隐修者居所 Hermitage | 适于独居、又能获得基本供养的地点 | 小型住所、礼拜空间、菜地、水源和储物 | 不默认秘密地下室或魔法能力；历史宗教制度另核 |
| 小型修院 Small Religious House | 独立宗教用地 | 礼拜、住宿、厨房食堂、储物、园地及经营附屋 | 沿用修院篇，规模不足时可共处一组翼楼 |
| 修院农庄 Monastic Grange | 远离修院本体的经营土地 | 管事或经营人员住处、谷仓、畜舍、经营附屋 | 与修院本体区别，不复制完整回廊和大教堂 |
| 朝圣客舍 Pilgrim Hostel | 有真实圣地和朝圣路线的区域 | 通铺、厨房、储粮、取水、可能的礼拜空间 | 依具体接待组织出现，不是普通旅店换招牌 |
| 施济医院 Hospital | 有施济者、土地或供给支持的道路沿线或郊野 | 收容照料、厨房、住宿、礼拜、储藏与庭园 | 延续修院篇的照料含义，不采用现代急诊科室组织 |
| 麻风院 Leper Hospital | 有隔离照料制度与供养条件的城外或道路旁 | 居住、厨房、礼拜、取水和相关经营附屋 | 地域性候选；正常使用时即可能独立存在，不仅是灾后营地 |
| 墓园礼拜堂 Cemetery Chapel | 有独立墓地、家族或机构葬地的地点 | 礼拜、丧葬用品储藏、墓园及条件性的看守住处 | 墓地可以没有礼拜堂，不能因原版有墓园就一律加盖 |
| 家族陵墓 Family Mausoleum | 贵族或富裕家族的特定葬地 | 墓室、纪念和祭祀空间、封闭入口 | 基准期的具体地域形制待核；不默认庞大可通行地下迷宫 |
| 圣泉礼拜建筑 Holy-well Chapel | 有宗教传统与人群活动的泉水地点 | 小礼拜或遮蔽建筑、取水设施、条件性的看守空间 | 自然泉不是建筑；只在有相应文化选型时加入 |

路边十字架、圣像龛、界碑、墓碑和石环作为露天构筑物或遗迹另记，不分别包装成完整房屋。

### 3.7 值守、防御与权力据点

| 建筑类型 | 选址与职能 | 主要空间与附属设施 | 与相近类型的区别 |
|---|---|---|---|
| 道路哨所 Guard Post | 重要路口、边界或运输路线 | 值守、少量守军睡眠炊事、武器物资储藏、围护 | 小型值守据点，不能直接套大型要塞院落 |
| 瞭望塔 Watchtower | 有实际观察任务及视野的高地 | 登高观察、值守、储物、少量休息空间 | 与住宅塔楼、门楼及现代消防瞭望塔的用途分别判断 |
| 烽火台 Beacon Station | 有组织的警报传递视线节点 | 信号设施、燃料储藏、守望人员遮蔽或住处 | 信号网络与补给是条件，不用魔法通信解释功能 |
| 关隘堡 Pass Fort | 需要控制的山口、峡道 | 门楼或防御塔、守军住所、厨房、粮库、取水 | 沿用城堡篇，可无堡外居民区 |
| 桥头堡 Bridge Fort | 战略桥梁的入口或岸段 | 守军住所、防御入口、物资库、值守空间 | 有军事防护任务，区别于普通桥梁看守住宅 |
| 小型边堡 Border Fort | 有常驻守军及区域控制需求的边地 | 防御围院、守军与指挥住所、供应仓储、马厩 | 与临时营寨、领主家庭城堡分别调查 |
| 港防堡 Coastal Fort | 港口或河口的入口控制位置 | 围墙塔楼、值守、补给储藏、条件性的住所 | 沿用城堡篇；不默认基准期配备后期炮台 |
| 设防仓库 Fortified Storehouse | 需保护的粮食、贵重货物或军事补给节点 | 受控仓储、守卫空间、管理住处和装卸院 | 以保管货物为核心，不等于领主城堡缩小版 |
| 独立领主城堡 Castle | 控制领地、路线或经营区的地点 | 居住大厅、服务建筑、防御、仓储和马厩 | 无附城仍可成立，完整类型见城堡篇 |
| 独立拘押堡 Prison Castle | 明确有拘押职能和持续供养的设防地点 | 守卫生活、拘押空间、厨房仓储、受控院落 | 条件性用途方案，不把原版大型现代监狱逐间中世纪化 |

### 3.8 临时营地与被占据的建筑

| 地点类型 | 成立条件 | 遮蔽建筑与设施 | 分类处理 |
|---|---|---|---|
| 行旅营地 Travellers’ Camp | 可停驻、有水源的道路沿线 | 帐篷或简易棚、炊事点、行李与牲畜停放 | 短期地点，区别于固定收费旅店 |
| 商队营地 Caravan Camp | 运输队伍集中驻留 | 帐篷、车货停放、炊事、护卫值守、牲畜围护 | 与转运货栈区别；不要求固定仓房 |
| 朝圣营地 Pilgrim Camp | 朝圣路线或圣地附近的阶段性人流 | 简易遮蔽、公共炊事、取水与临时宗教设施 | 只在相应人流成立，不泛化为所有路边营地 |
| 军队营寨 Military Camp | 行军、驻守或围城等明确军事活动 | 帐篷、指挥与补给区、炊事、牲畜、条件性土木围护 | 现场规模与供给另核，不作为永久要塞的损坏版 |
| 避难营地 Refugee Camp | 瘟疫、饥荒或战乱导致人群暂居 | 帐篷棚屋、炊事、物资存放、取水与废物处理 | 采用现有世界观，可依附废弃农庄、修院或独立扎营 |
| 匪徒营地 Bandit Camp | 有活动范围、藏身和补给来源 | 棚屋或帐篷、赃物储藏、炊事、值守 | 既可独立搭建，也可占据旧建筑；组织设定沿用敌人篇 |
| 隐蔽交易窝点 Clandestine Depot | 有具体违禁或逃税贸易背景 | 隐藏货物、短住遮蔽、小型装卸或靠船点 | 作为货栈、岸边小屋或地窖的用途变体，不凭隐蔽增设新产业 |

匪徒占据猎庄、溃兵占据磨坊、难民占据修院、居民将地窖用作避难所，均记录为“原建筑类型＋当前用途”。不再为每个占据者组合重复建设一套建筑类别。

## 四、废墟、地下空间与探索变体

| 基础建筑或地点 | 可用的独立探索形态 | 仍需保留的原用途线索 |
|---|---|---|
| 孤立住宅、猎庄、乡间宅邸 | 荒宅、烧毁宅院、封闭宅院、被占据住宅 | 炉灶、起居、储物、附院和出入道路 |
| 农庄、谷仓、牧场 | 荒废农庄、倒塌谷仓、空置畜舍 | 耕地边界、粮食处理、饲料与饮水设施 |
| 磨坊、作坊、窑场 | 废磨坊、废窑场、停工作坊 | 动力来源、炉窑、原料堆场和装卸关系 |
| 矿场、采石场 | 废矿、封闭坑道、淹水作业区 | 矿口、工具与矿料处理设施、废石及运输道路 |
| 城堡、哨塔、关隘堡 | 废堡、断塔、失守关卡 | 原入口、守军供应、取水和防御关系 |
| 修院、礼拜堂、墓园 | 废修院、废弃礼拜堂、封闭墓室 | 礼拜、居住、丧葬与经营空间各自的位置 |
| 古代宅院、公共建筑或堡垒遗迹 | 古代遗址及后世再利用的小屋或据点 | 具体文化和历史原型待选，不统称为功能不明的“神秘建筑” |
| 住宅、工坊、仓储建筑的地窖 | 藏货、短期避难、隐秘作业空间 | 与地面入口、通风、照明和原本储藏用途的关系 |
| 人工开凿墓室、岩窟礼拜或隐修空间 | 以山体入口为核心的独立地点 | 人工建造用途与自然洞穴分别辨认，具体原型待选 |

完整、失修、烧毁、倒塌、遭掠夺、封闭和被占据是状态；不将每种状态计算为新的建筑类型。地下空间也不自动成为另一个大型地点；只有入口、体量或用途确有区别时再单独选型。

自然洞穴、泉水、巨兽巢穴、古战场和普通沉船可成为特殊地点，但本篇不展开其完整目录。沉船具有船体结构，后续应按船型调查；本轮不以现代船骸推导中世纪船舱。

## 五、后续逐项调查的记录内容

每种建筑继续核查具体历史原型和适用地域，记录服务对象、独立选址的原因、道路与水源、主要工作流程、内部空间、附屋、露天设施、材料与楼层。目录中已标明条件的信使站、航标灯塔、动力作坊等保留候选身份，核到依据后再确定方案。

住宅、农庄、城堡、修院及生产建筑本体分别沿用既有分案。本篇补充其独立存在的组合与选址，不改写为另一套重复建筑。数量、尺寸、驻守人数、物品投放和损坏概率留到相应建筑完成细查后再定。
