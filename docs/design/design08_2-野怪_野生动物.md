# 策划案 008_2：野怪体系（二）—— 野生动物

> 本案定义 14 种中世纪欧洲野生动物及其玩法定位。

## 一、掠食者

### 1. 棕熊 (Brown Bear)

> 别惹。

| 字段 | 值 |
|------|-----|
| 耐打基准 | 200 |
| 速度 | 130 |
| 近战能力 | 5 |
| 基础伤害骰数 | 4 |
| 每骰点数 | 8 |
| 附加伤害 | `[斩击 6]` |
| 闪避 | 0 |
| 钝击防护 | 6 |
| 斩击防护 | 4 |
| 穿刺防护 | 2 |
| 攻击性 | -5 |
| 士气 | 80 |
| 激怒条件 | 受伤、玩家靠近幼崽 |
| 恐惧条件 | 火焰 |

> 伤害：4d8 bash + 6 cut = 4~32 bash + 6 cut。一掌下去你不穿甲就骨折。

**行为**：被动中立。玩家靠近幼崽或攻击后转为敌对。不逃跑。

**屠宰产物**：harvest bear brown
- flesh: meat bear (尸重比例 0.40) / fat bear (0.10)
- skin: pelt bear brown (0.03)
- bone: bone large (0.12)
- offal: liver bear (0.01) / stomach large (最多1份)

**解剖产物**：dissect bear
- bear claw / bear tooth

## 六、地域分布与刷新

| 地形 | AnimalGroup | 内容 |
|------|-----------|------|
| `forest` | GROUP FOREST | 棕熊(2%)、狼(8%)、野猪(10%)、赤鹿(8%)、狍子(15%)、狐(10%)、獾(5%)、野兔(15%)、雕鸮(3%) |
| forest thick | GROUP FOREST DENSE | 棕熊(5%)、狼(10%)、野猪(15%)、赤鹿(5%)、獾(8%) |
| swamp water | GROUP SWAMP | 河狸(3%)、水禽(20%) |
| `grassland` | GROUP PLAINS | 野牛(5%)、野兔(15%) |
| `mountain` | GROUP MOUNTAIN | 金雕(8%) |
| `night` 追加 | — | 狼权重翻倍、狐权重翻倍、雕鸮权重翻倍 |
| `winter` | — | 蝰蛇权重=0、狼权重×1.5 |
