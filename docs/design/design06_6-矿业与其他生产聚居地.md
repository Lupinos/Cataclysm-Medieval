# 矿业与其他生产聚居地

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

收录由矿产、石材、盐、木材或集中生产吸引常住或季节性劳动力的聚居地。矿山、采石场、窑场本身是生产地点；有持续居住和生活供应时才作为聚居地调查。矿业城镇可以具有城镇篇的全部民用功能，不能只画成矿口加一排工棚。

## 二、历史原型

### Rammelsberg与Goslar：矿山及相关城镇

德国Rammelsberg矿山与Goslar说明矿产开采、财富、城市生活及区域运输之间的关系。UNESCO同时指出现存城市住宅及矿业水利包含多个后期阶段；大规模上哈尔茨水利发展主要在16世纪末以后，不能整套用于约1400年。[UNESCO遗产说明](https://whc.unesco.org/en/list/623/)

本原型支撑矿山与城镇的关联，不足以确定本期全部井架、动力设备及冶炼炉型。以下采石、盐业、林业及其他专业生产类型为选型候选，具体基准期遗址继续另选。

## 三、具体聚居地类型

| 类型 | 聚居核心 | 优先建筑组合 |
|---|---|---|
| 矿村 Mining Village | 开采点附近的劳动力及供应 | 矿工住宅、工具棚、矿料储放与处理建筑、铁匠铺、食品供应和礼拜建筑 |
| 矿业城镇 Mining Town | 矿业经营、管理和贸易集中 | 矿务管理房、商人宅邸、矿料货栈、专业工坊及普通城镇建筑 |
| 采石聚居地 Quarry Settlement | 石料开采与初步加工 | 工人住所、石匠棚、工具修理铺、车棚与畜力运输配套 |
| 盐业聚居地 Salt-making Settlement | 盐源和加工、储运 | 工人住宅、煮盐屋或盐田管理建筑、盐仓、燃料棚、货栈和条件性的征税设施 |
| 林业营地 Woodland Camp | 伐木、烧炭或森林内季节性生产 | 临时住棚、工具棚、木料储放与运输附屋；不预设常住村庄全部公共建筑 |
| 林业村庄 Woodland Village | 持续居住并以森林资源维生 | 家庭住宅、木作坊、储藏和畜养附屋，配套林业作业点 |
| 专业工坊聚居地 Craft Settlement | 某种生产集中形成常住或季节性社区 | 工人住宅、相应作坊、原料与成品仓库、燃料供应建筑 |

专业工坊聚居地可继续选取冶铁、陶业、玻璃等方向；它们也可能只是城镇的一片作坊区，无须每项生产都另建一种独立城镇。

## 四、典型建筑目录

| 建筑 | 功能与区别 | 选型条件 |
|---|---|---|
| 工人住宅、季节性住棚 | 家庭或临时劳动力生活 | 常住户住宅与季节营棚分开，不套用近代工业宿舍 |
| 矿务管理房、经营者住宅 | 组织、记账、保存文书和贵重产物 | 可合设；机构名称及权限依原型核定 |
| 工具棚、矿料仓、分选棚 | 工具保管与矿料处理 | 露天分选地不另算房屋，具体设备另核 |
| 冶炼作坊、锻铁作坊 | 从矿料取得金属与进一步加工 | 分清采矿、冶炼、精炼和锻造，不将全部阶段塞入普通铁匠铺 |
| 铁匠铺 | 修理工具、车辆铁件和生产设备 | 可服务矿区或采石场，与专业冶炼建筑分别调查 |
| 石匠作业棚 | 石材修整与初步制作 | 与开采面、废石堆及运输道路关联 |
| 煮盐屋、盐仓 | 盐水加热及盐货储藏 | 仅适用于相应制盐工艺；海边晒盐不强设煮盐屋 |
| 燃料棚、木炭仓 | 存放干燥燃料 | 烧炭土窑或炭堆属于生产设施，不等同一栋“烧炭房” |
| 木工棚、锯木作业棚 | 木料加工 | 水力锯木等设备须按地域和年代选原型，不作所有林村标配 |
| 陶坊、窑棚 | 制坯、干燥、烧成与存货 | 陶窑、干燥棚及住处可组成院落 |
| 玻璃作坊 | 高温生产与器物成形 | 原料、燃料与工人住所配套；具体炉型、规模和时期待核 |
| 车棚、马厩、驮畜棚、饲料仓 | 原料、燃料和产品运输 | 依道路和运输方式选用 |
| 粮食仓、烤房、麦酒屋、旅店 | 劳动力日常供应 | 规模不足时由家庭生产或邻近村镇供给 |
| 礼拜堂、教堂、管理与交易建筑 | 常住社区的公共生活 | 依聚居规模和组织出现，不给临时营地固定市政厅 |

配套设施：矿口、井道、露天采坑、采石面、洗选场、矿渣与废石堆、盐田、贮卤池、炭堆、窑炉、木料场、运输道路及条件性的引水沟和水轮。这些生产设施与建筑共同调查，设备年代不能从遗址当前展示状态推定。

## 五、空间关系与细查重点

按原料取得、初加工、燃料供应、储藏和运输逐段判断需要哪些建筑。矿山与冶炼点可以分离；森林营地可以向城镇供炭；盐场可以依赖外来粮食和燃料。生产地点、工人生活区和交易管理中心之间的距离属于具体选型内容。

下一步分别补选基准期矿村、采石场、盐场、烧炭营地及窑场原型，再细查住宅、工坊、仓库与运输配套。未核实的机械、炉型与生产能力保留待核。
