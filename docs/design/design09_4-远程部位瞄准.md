# 远程部位瞄准

## 目标与操作

射击时可查看并选择目标身体部位。界面显示部位名称、大小与命中预期，允许在瞄准时切换；同一目标可记住上次选中的部位。

## 风险与收益

小部位更难可靠命中，近处、训练充分且瞄准稳定时更容易精确射击。头、腿、翼等部位提供不同战术收益，躯干仍应是可靠的基础选择。

## 身体连接关系

射偏后的落点应符合身体结构：瞄准前肢时，邻近躯干可能被击中；不能把任意部位当成与全身其他部位等距。具体算法属于实现方案，不在本案规定。

## 界面规则

部位切换应与当前射击操作兼容，快捷键需避免冲突。显示的“命中目标”和“命中指定部位”要区分，不能把内部抽样权重当成玩家看到的最终命中率。
