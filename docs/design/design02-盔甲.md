# 策划案 002：盔甲体系（14 世纪末至 15 世纪初过渡期）

## 时代与设计目标

基准时期约为 1375–1425。锁甲、板甲衣、早期布里根丁与板甲部件并存；不同地区、财力和用途决定装备组合，不按身份严格解锁固定套装。维斯比型板甲衣作为较早形制的留用装备；成熟萨莱特盔与护颚组合、杰克甲等较晚形制另作扩展，不视为这一时期的普遍配置。

目标是让玩家在覆盖部位、防护、负重、热负担、活动空间及维护成本之间选择。金属甲不等于无法运动，布甲也不等于无效；任何防具都不能保证免疫同类攻击。

## 一、穿着组合与层次

### 1.1 先区分垫衣用途

- **薄型甲下垫衣（arming garment / aketon）**：贴合身体，提供一定缓冲与承托，供锁甲或板甲下穿；不应拥有独立厚布甲同等的防护。
- **独立厚型 gambeson**：以多层织物或填充物提供主要防护，更厚、更热，适合作为主甲；不默认适合继续塞在整套金属甲下面。名称随地区与年代有交叠，这里按用途区分。
- **锁甲**：可作主要防具，也可补充板甲未覆盖的部位；全长锁甲与局部锁甲补片是不同负重方案。
- **外层主甲**：板甲衣、布里根丁或胸背甲通常三选一，不把它们设计成逐级全部叠穿的升级链。

典型组合为：内衣＋薄垫衣＋锁甲；内衣＋薄垫衣＋布里根丁；内衣＋薄垫衣＋锁甲或局部补片＋板甲部件。民兵可选择内衣＋厚型 gambeson＋头盔。

### 1.2 CDDA 层位的设计取向

下表是本模组的目标取向，不是原版当前物品层位或已实现映射。原版部分锁甲使用外层并借附加护甲结构组合外甲，具体机制另见调研。

| 装备 | 层位取向 | 叠穿含义 |
| --- | --- | --- |
| 亚麻内衣 | 贴身层 SKINTIGHT | 吸汗衣物，不承担厚垫衣的防护定位 |
| 薄型甲下垫衣 | 普通层 NORMAL | 与覆盖同部位的普通层锁甲同穿时，接受有限的额外累赘 |
| 独立厚型 gambeson | 普通层，厚款可同时占外层 | 与完整金属主甲竞争活动空间，不作为无代价的通用内衬 |
| 锁甲衬衫、锁甲大衣 | 普通层 NORMAL | 为外层主甲留出位置；长袖、裙摆的覆盖单独权衡 |
| 胸背甲、板甲衣、布里根丁及主要板甲肢体件 | 外层 OUTER | 同部位的外层主甲互为替代；分段肢体件按实际覆盖避免不必要冲突 |
| 背包、武器吊带、外挂袋 | 外挂层 BELTED | 用于携行装备；不能因为甲片有绑带就把它移到该层 |

**两件普通层衣物会不会竞争？会。** 同层且覆盖相同子部位时，除两件自身的累赘外还有叠穿惩罚；并不是“第二件不能穿”，也不是固定翻倍全部累赘。同层但覆盖互不重叠的部位，不因同层名称自动冲突。跨层按正确顺序穿着可避免这类冲突，但基础累赘、重量与热负担仍然存在。

本案接受薄垫衣＋锁甲的适度叠穿代价，通过薄垫衣自身较低的累赘保持可用性，不将其移到贴身层或外挂层来凭空消除成本。若后续验证显示代价过高，可评估包含必要薄内衬的完整锁甲衣，但必须同时计入内衬重量、防护与保暖，不允许重复获得“免费内衬”。具体计算见[穿衣分层调研](../vanilla/code_clothing_layer_system.md)。

## 三、典型装备与战术选择

| 使用者 | 典型选择 | 优势与代价 |
| --- | --- | --- |
| 农民、流民 | 日常衣物、毡帽或旧头盔 | 成本低，主要依靠距离、地形和逃离 |
| 民兵、征召兵 | 厚型 gambeson＋锅盔 | 有实际防护，四肢与面部仍可能暴露，炎热时负担明显 |
| 职业步兵、弓弩手 | 薄垫衣＋锁甲或轻型布里根丁＋头盔 | 按任务在覆盖与动作空间之间取舍 |
| 重装步兵、骑士 | 薄垫衣＋外层主甲＋锁甲补充＋肢体甲 | 覆盖更完整，价格、负重、维护与热负担更高 |

不再给社会阶层分配一个“全身覆盖率”百分比。覆盖应按头、颈、躯干及四肢分别描述；躯干保护好不代表面部、腋部或腿部也受保护。

## 四、防护原则

| 类型 | 设计原则 |
| --- | --- |
| 斩击 | 铆接锁甲和钢板对切割有明显优势；厚织物亦有价值，但受结构和厚度限制 |
| 穿刺 | 尖端形状、能量、环扣结构、钢板质量与命中位置共同决定结果；不设“尖箭必穿锁甲”或“钢板免疫箭矢” |
| 钝击 | 刚性甲可分散载荷，垫衣可缓冲；强力冲击仍可致伤，不把板甲或布里根丁一律设成怕钝击，也不把织物设成万能吸震层 |
| 缝隙攻击 | 防具结构留有活动和观察空间；应以真实覆盖范围与命中位置表现，而非只降低整件甲的统一防护 |

锁甲、板甲与内衬协作时有收益，也有边际成本。完整板甲不必强制搭配最厚 gambeson 和全长锁甲；局部锁甲补片允许更合理的重装组合。不同物品的覆盖存在关联，不能把几件护甲的覆盖率或抗性简单相加作为必然效果。

## 五、负重、活动与经济

- 重量比较必须使用相同口径：胸背甲与胸背甲比较，整套含头盔和肢体甲的装备与整套比较。不能把“仅胸甲”写成 15–25 kg 的整套重量。
- 躯干金属主甲可先按约 5–12 kg 的设计区间细分；锁甲长短、袖长、织法和环结构会显著影响重量。这些是调参起点，不是每件历史实物的测量结论。
- 活动负担取决于贴合、裁剪、重量分布、关节空间及覆盖；不能仅凭“大甲片”判定笨重，也不能仅凭“小甲片”判定灵活。
- 护甲不自带本案新增的硬力量门槛或穿甲熟练度惩罚；不把“穿板甲必定走路掉耐力”描述为既有机制。基础累赘、负重和热负担已是需要一起验证的成本。
- 好材料与合体工艺可以改善防护或活动，但精美织物、镀金和纹章主要增加价格与身份价值，不自动提高防护。
- 维修按损伤类型区分：织物缝补、环扣替换、铆钉与甲片修理、整形均需相应材料和工具；廉价材料不保证低工时。

## 六、材料与扩展范围

材料按织物、皮革、铆接锁环及金属板的构造区别，不把钢材牌号直接等同于社会阶层，也不把“硬皮”设为接近钢板的低成本防护。具体材料抗性、JSON 字段、继承关系和物品参数属于技术方案；既有机制参考[材料系统调研](../vanilla/code_material_system.md)，旧参数仅见[技术归档](../archive/technical/medieval_armor.md)，不作为当前实现承诺。

过渡期躯干甲的定位与建议区间见[布里根丁与板甲衣细分](design02_1-布里根丁与板甲衣细分.md)。盾牌、马铠、骑乘防护以及铁匠服务另行设计，不在本案列出实装步骤或完成清单。
