# 策划案 002：盔甲体系

## 一、范围与分类提纲

本体系以游戏中的装备选择和配装为目标，整体风格参考约1375–1425年的欧洲过渡期盔甲，也可借鉴其他时期与地区的结构。历史提供外形、工艺和参数量级参考；是否采用某种装备、怎样选材与组合，由游戏定位、结构合理性和编写成本决定。

| 分案 | 内容 | 分类边界 |
|---|---|---|
| [02_1 板甲](design02_1-板甲.md) | 金属头盔、胸背甲、分节腹甲及四肢手足硬板护具 | 以成形硬板承担防护；按实际部件列形制 |
| [02_2 布面甲与片甲](design02_2-布面甲.md) | 板甲衣、布里根丁、杰克甲，附鳞甲与札甲 | 金属片固定在织物或皮革承载层；布面甲是本案统称，不要求外罩一定是布 |
| [02_3 皮甲](design02_3-皮甲.md) | 模压、硬化皮革与条片加强护具 | 普通皮衣、皮靴不自动算作战斗甲 |
| [02_4 绗缝甲与武装衣](design02_4-绗缝甲与武装衣.md) | 独立织物甲、金属甲下垫衣及配套软护具 | 区分主要防护与承托用途，不按名称强行划出统一厚度 |
| [02_5 锁甲与锁板甲](design02_5-锁甲.md) | 锁甲衣、护颈、补片、腿具，附锁板甲 | 按剪裁、接合、环结构与覆盖识别，不用长袍/短袍冒充形制 |

鳞甲、札甲作为片甲分支并入02_2，札片头盔和护颈也在该篇维护；锁板甲并入02_5。当前采用欧洲、西亚与草原路线，不设置独立藏系装备。

缀条式肢体护具若以皮革承载金属长条，列入皮甲篇的复合护具分支；不是另造“轻便板甲”档次。盾牌和马甲不在本轮人体穿戴盔甲目录内。

## 二、穿着层位与组合

| 装备 | 本模组指定层位 | 组合要求 |
|---|---|---|
| 亚麻内衣 | 贴身层 | 日常衣物另见衣物策划 |
| Gambeson、aketon、武装衣 | 普通层 | 薄甲下衣与厚独立甲分别描述；厚款不能默认舒适地塞进全套金属甲 |
| 锁甲及锁甲补片 | 普通层 | 按实际覆盖叠穿，不将局部补片当全身锁甲 |
| 板甲及金属头盔、独立板甲护颚 | 外套层 | 头盔与手足部件按各自形制描述 |
| 布面甲 | 外套层 | 板甲衣、布里根丁、杰克甲通常与同部位胸背甲择一 |
| 皮甲、鳞甲、札甲、札片头盔/护颈、锁板甲 | 外套层 | 主甲、头盔与护颈分别穿戴，不因换甲种额外开放主甲叠穿层 |

薄垫衣＋锁甲＋外层主甲是可选组合；gambeson 与锁甲同为普通层，是本轮明确的设计决定，同部位重叠应接受叠穿代价。单件重量、热负担、活动空间及覆盖缺口均需保留。绑带固定不构成归入外挂层的理由。

上述层位是本模组的设计目标，不代表原版现状或已经实现。原版锁甲及附加护甲的组合方式另见[穿衣分层调研](../vanilla/code_clothing_layer_system.md)。同层且覆盖相同子部位时，基础累赘之外还可能产生叠穿代价；不同层按序穿戴仍承担基础累赘、重量和热负担，刚性件也须检查空间冲突。

## 三、材料可选性

材料按装备定位选择，并分别说明基材、品质与热处理。不同形制可以采用相同材料，同一形制也可有材料变体；历史实物用于参考，不限制游戏方案必须复制其成分。

| 材料或状态 | 可选用途 | 限制 |
|---|---|---|
| 锻铁/熟铁、碳含量很低的铁料 | 锁环、金属板、铆钉；适合保留低成本或早期工艺变体 | 夹渣与锻接质量另记；不等于铸铁 |
| 低碳钢 | 锁环与各类金属甲板的可选基材 | 淬硬能力有限，不能单靠淬水就成为优质硬甲 |
| 中碳钢 | 有相应冶金条件的甲板或锁环 | 按防护、韧性、成本和加工条件选择；淬硬状态另列 |
| 高碳钢 | 可用于需要更高硬度的设计变体，结合韧性和工艺权衡 | 不是所有甲种的默认高级版本；韧性和热处理要求不能省略 |
| 表面渗碳 | 低碳基材的工艺选项 | 需区分渗碳深度、芯部与表面；不自动等于已经淬硬 |
| 淬硬/回火钢 | 适合成分且工艺受控的金属护具 | 是加工状态而非独立碳含量；不能由抛光或装饰推定 |
| 成分不均、夹渣较多的铁钢料 | 普通品质或材料品质较低的变体 | 回收原料不必然劣质；锈蚀是状态，不是材质类别 |
| 亚麻、棉、羊毛、丝及填充纤维 | 承载织物、垫衣、装饰面料 | 分清纤维、织法和填充；天鹅绒不是固定的棉材料 |
| 皮革、未鞣生皮、硬化皮革 | 扣带、承载层、具体皮护具 | 三者不互换；硬化工艺、厚度、湿度影响性能 |

形制、材料与热处理分别选择。材料变体应带来明确的防护、重量或成本取舍，不仅增加一个名称。[材料工艺参考](https://link.springer.com/article/10.1007/s12520-019-00979-1)

## 四、分案结构与装备关系

各分案统一采用：一、范围与穿戴单位；二、原型参考；三、头颈目录；四、躯干与腰胯目录；五、肩臂与手部目录；六、腿与足部目录；七、分区材料与厚度；八、配装与装备关系。原型参考简要记录结构与可用数据，目录和组合表直接给出游戏方案。

- **独立件**：整体穿脱的一件装备，可包含多块甲片、衬里和扣带。
- **内含构件**：面甲、指片、衣袖、裙摆、缝附补片等在所属装备内描述，不单独增加物品。
- **组合**：列出成员和件数，说明谁补充哪个部位、哪些选项互相替代。组合不再额外生成一件重复套装。
- 左右单侧或成对说明清楚；材料、颜色和饰面变化归同类变体，不为每种变化另起类别。
- 配装按覆盖、接口、活动空间和负担决定，跨甲种搭配也可成立；不要求成员来自同一历史套装。
- 是否新增装备取决于它是否提供有意义的选择。暂不需要的部位留空，避免为补满全身目录增加编写负担。

### 参数与参考

每种装备写明识别特征、穿戴单位、覆盖与缺口、材料、分区厚度、重量和尺寸。原型名称、年代和来源集中在参考节，不在每个配装条目重复讨论。

历史测量标为参考值，游戏参数标为设计值；未确定的参数标为待定。可以依据结构与平衡需要制定参数，无需等待同年代实物的完整测绘。锁甲分别记录环结构，织物甲分别记录面里和填充；定值时核算覆盖面积、用料与重量。

## 五、防护与装备选择原则

同覆盖范围比较重量与活动空间；整副臂甲不能与单个前臂筒直接比轻重。金属板受力分散、锁环抗割、织物承托与缓冲都受结构影响；避免“锁甲必怕箭”“厚布极高抗钝”“板甲穿上不能跑”等无条件结论。面甲、关节缝、腋窝、手心、膝后等缺口由具体形制决定。

社会身份影响采购与装饰，但不直接决定钢材碳含量或固定套装。普通款、合体定制款、装饰款、战场款与比武款按实际差别描述，不将镀金和天鹅绒自动转成防护优势。后续按装备定位确定价格、负担与防护，保持同类比较的一致性。

定值时区分保护部位、该部位的覆盖概率与材料分布；躯干上下分区不代表正面与背面。穿着护甲的武器命中参数不能直接当作持械攻击的穿戴罚值，动作负担应根据实际机制验证。护甲不因此新增硬力量门槛或穿甲熟练度要求。

板片大小不能单独决定灵活性，贴合、重叠、开口与重量分布需一并比较。维修区分织物缝补、环扣替换、甲片与铆钉修理；材料便宜不表示工时低。覆盖率或抗性不能简单相加为组合的必然防护。先分别比较单件及完整配装，再校准斩、刺、钝与箭矢条件；建议区间不代表实机平衡已经验证。

## 六、对应004武器的地域配装

### 6.1 共用与选择规则

下表是游戏配装路线，不是历史原装套装或阵营装备锁。R0为通用底库，R1–R10从底库与实际有区别的结构中选配。每条路线都有头、主甲、肢体及03衣物选择；轻装不必穿齐所有重甲件。地域改变常见搭配、剪裁与外观，不产生固定攻防加成。

短袖主甲不自动保护前臂，靴筒不是钢胫甲，札甲短护肩不是完整臂甲。按实际覆盖补局部护具；颜色、饰面、钢材与轮廓变化优先归变体。

### 6.3 札甲的头部与甲体关系

札甲描述穿缀甲片的结构，既可用于甲体，也可用于头盔；穿札甲的人也可戴整体或拼接金属盔。此前目录缺少头盔不代表这些装备没有头部防护。

当前游戏方案为：骑乘札甲、札片头盔、札片护颈帘共三个独立件；甲体短护肩和甲摆内含。可用圆锥盔替代札片盔，用匹配锁甲帘替代札片帘，不双重计入。头盔与护颈见02_2，其他金属盔见02_1，锁甲兜帽/挂帘见02_5；附件轮廓、盔缘及连接方式需匹配。
