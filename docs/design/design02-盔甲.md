# 策划案 002：盔甲体系（14 世纪末 ~ 15 世纪初过渡期）

## 时代定位

| 项目 | 说明 |
|------|------|
| 时期 | 约 1375–1425（百年战争中后期） |
| 阶段名称 | **过渡盔甲期**（Transitional Armor） |
| 特征 | 锁子甲（mail）仍为主流基础层，板甲正在快速普及但尚未全覆盖 |
| 代表战役 | 阿金库尔（1415）、尼科波利斯（1396） |

## 一、盔甲穿着层次

中世纪盔甲不是"穿一件"，而是**逐层叠加**，不同阶层在"能穿到第几层"上分化：

```
第 1 层：内衣（linen shirt / braies）
  ↓
第 2 层：武装衣 gambeson / aketon（厚棉麻填料，防钝击 + 提供缓冲）
  ↓
第 3 层：锁子甲 hauberk（铁环编制，防割伤 / 对刺击弱）
  ↓
第 4 层：板甲 / brigandine（最大防护层，贵族和重装兵专享）
```

### 2.1 头部

| 盔甲 | 材料 | 覆盖 | 适用阶层 | 时期匹配度 |
|------|------|------|----------|------------|
| 亚麻兜帽 | 棉麻 | 头、颈 | 农民 | 全时期 |
| 厚毡帽 / 皮盔 | 皮革 | 头 | 民兵、轻步兵 | 全时期 |
| **Kettle Hat（锅盔）** | 铁 | 头顶（宽檐） | 步兵、弓箭手 | 极佳 |
| **Bascinet（尖顶盔）** | 钢 | 头顶 + 侧 | 职业兵起 | 核心盔 |
| **Bascinet + Hounskull Visor（猪面盔）** | 钢 | 全头 + 面 | 重装兵、骑士 | 核心盔 |
| Great Helm（巨盔） | 钢 | 全头 | 骑士（渐退场） | 末期，罕见 |
| Sallet（轻盔） | 钢 | 头顶 + 后半 | 骑士（新兴） | 早期雏形 |

### 2.2 颈部

| 盔甲 | 材料 | 覆盖 | 备注 |
|------|------|------|------|
| 锁子甲护颈 aventail | 铁环 | 颈 + 肩上部 | 附在 bascinet 底部 |
| Standard（皮革护领） | 硬皮 | 颈 | 廉价替代 |
| Gorget（板甲护喉） | 钢 | 喉 + 锁骨 | 贵族专享 |
| **Bevor（板甲护颚）** | 钢 | 喉 + 下颌 + 脸颊下 | sallet 搭档，15 世纪骑士标志 |

> **Bevor vs Gorget 区分**：Gorget 环绕颈部防护（前喉 + 后颈），主要用于封堵头盔与胸甲之间的缝隙。Bevor 则是面部下半部分的防护（下颌、脸颊下部、前喉），与 sallet 头盔配合形成完整头部防护——sallet 盖住头顶+后脑，bevor 盖住下巴+前喉+脸颊，两者结合达到近似 great helm 的防护但更轻、视野更好。这是 15 世纪中期板甲骑士的标准配置。

### 2.3 躯干

| 盔甲 | 材料 | 保护类型 | 适用阶层 | 特征 |
|------|------|----------|----------|------|
| 亚麻上衣 | 棉麻 | 无 | 全阶层（内层） | 没人只穿这个出门 |
| **Gambeson / Aketon** | 多层棉麻填料 | 钝击、割 | 全阶层 | 最基础的独立盔甲 |
| **Leather Armor / Cuir Bouilli** | 硬化皮革 | 割、钝击 | 民兵、轻骑 | 比 gambeson 贵但轻 |
| **Mail Hauberk** | 铁环 | 割（弱刺） | 职业兵起 | 覆盖到膝盖，核心装备 |
| **Coat of Plates** | 铁板铆在内衬上 | 刺、割 | 骑士、重装兵 | 过渡期前半段主流 |
| **Brigandine** | 小钢片铆于布内 | 刺、割、钝击 | 骑士、军官 | CoP 的进化版，灵活 |
| **Cuirass（胸甲 + 背甲）** | 钢 | 全面 | 骑士、领主 | 本时期末开始普及 |

## 三、社会阶层 × 盔甲能力矩阵

### 总览表

| 阶层 | 典型配置 | 概要 | 覆盖率 |
|------|----------|------|--------|
| 农民 / 流民 | 亚麻衣 + 可能有毡帽 | 几乎裸奔 | 0~10% |
| 民兵 / 征召兵 | gambeson + kettle hat | 能抗几刀 | 30~50% |
| 雇佣兵 / 轻装步兵 | gambeson + mail hauberk + bascinet | 标准配置 | 60~75% |
| 重装步兵 / 下级骑士 | mail + brigandine + bascinet with visor + 臂甲部分 | 铁乌龟 | 80~90% |
| 骑士 / 高级军官 | 完整过渡期板甲 + 全副武装 | 几乎全覆盖 | 90~95% |
| 领主 / 王室 | 定制全身板甲 | 无人能轻易穿透 | 95%+ |

### 场景化速查
- 野外遇到一个拿矛的民兵：gambeson + kettle hat → 砍躯干几乎没效果，砍四肢和脸
- 强盗头目：mail hauberk + bascinet → 必须用钝器或穿刺武器
- 骑士团遭遇战：过渡期板甲 → 除非有戟/长弓/弩，否则赶紧跑
- 遗迹里发现一副 **Cuirass**：本时期早期胸甲的标志性高端防具，捡到等于赚到

## 四、损伤与防护机制

### 伤害类型对应

| 类型 | 有效武器 | 畏惧的盔甲 |
|------|----------|------------|
| 斩击（Cut） | 剑、斧 | mail、plate 均有效防御 |
| 穿刺（Pierce） | 矛、箭、弩、匕首 | mail 弱，plate 极强 |
| 钝击（Bash） | 锤、棍、权杖（mace） | gambeson 提供缓冲，但 plate 怕变形 |
| 撕裂 | 钉头锤？ | 对 mail 有效（扯断铁环） |

## 后续防具体系

候选扩展包括更完整的板甲、头面防护、手足与关节护具。每件防具继续按社会阶层、覆盖范围、重量、防护和耐力代价分化；具体优先级尚待讨论。
