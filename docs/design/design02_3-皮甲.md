# 策划案 002_3：皮甲与皮革复合护具

父案：[盔甲体系](design02-盔甲.md)。

## 一、范围与穿戴单位

皮甲用于局部防护与轻型配装，包含硬皮护具和金属条加强皮护具。外罩式护具采用外套层；软皮衣物在日常衣物篇维护。

**独立件**整体穿脱；**内含构件**在所属物品内分区描述；**组合**列明所需的独立件，不再生成一件重复套装。

## 二、原型参考

原型用于提供外形、结构和参数量级；装备选型、材料与组合由本案确定。表中馆藏测量与第七章设计参数分别使用。

| 参考原型 | 采用的结构信息 | 可用参数 |
|---|---|---|
| 塔尔图条片加强护臂 | 皮筒包围前臂、金属长条加强、带扣闭合 | 现存皮3–5mm，条片约2mm厚、7–8mm宽；皮种研究提出马皮可能性 |
| 多德雷赫特Dd69-285 | T形外侧上臂护片 | 展开约25×19.5cm；其余厚度未定 |
| 多德雷赫特D-S1 | 关节处切口的厚皮指背片 | 牛皮原片约5mm；完整手套按游戏方案设计 |

普通皮革、硬化皮革与生皮分别选材；金属加强条与皮底分区记录。参考测量用于确定量级，具体形状和材料变体按装备定位选择。

参考：[Getty 术语记录](https://www.getty.edu/vow/AATFullDisplay?find=&logic=AND&note=&subjectid=300193359)；[原研究，231–237 页](https://amm.sanok.pl/wp-content/uploads/2017/06/IX.8_Maesalu_Peets.pdf)；[原研究，63 页起](https://www.archeologiedordrecht.nl/dds/up/ZmyofrkKafgR_Leather_in_Warfare_Late-medieval_leather_armour_from_excavations_in_the_Netherlands_Marloes_Rijkelijkhuizen_and_Marquita_Volken.pdf)；[《Antiquaries Journal》器物研究](https://www.cambridge.org/core/journals/antiquaries-journal/article/abs/latemedieval-bracer-in-the-british-museum1/AD4B30BF8C5C727E94C1AE6C6AFC89A3)；[Met 研究条目](https://www.metmuseum.org/art/collection/search/27203)；[馆方器物介绍](https://royalarmouries.org/objects-and-stories/up-close-online-exhibition/buff-coat-iii1929)。

## 七、分区材料与厚度

材料按总纲菜单和装备定位选定。第二章测量供量级参考；尚未确定的分区厚度标为待定，选定后结合覆盖面积核算重量。测厚分区不自动拆成独立装备。

## 八、配装与装备关系

| 配装/装备 | 成员与穿戴单位 | 替代与搭配 |
|---|---|---|
| 单侧皮臂组合 | T形上臂皮甲＋条片加强皮护臂，共两件 | 分别保护上臂外侧与前臂，肘部空缺保留；手套另配 |
| 加强护臂 | 皮筒、金属条、扣带共同组成一件 | 不按金属条数量拆物品；可与板前臂甲择一 |
| 皮指护片手套 | 指背护片固定在一只软手套上 | 护片并入手套，掌部与指背分别记录材料 |

局部皮甲可以与布甲或金属主甲搭配，按覆盖和活动空间选配，不要求集齐同材质全身套装。
