# 策划案 002_1：板甲

父提纲：[盔甲体系](design02-盔甲.md)。本篇按成形板片的形制、连接与实际覆盖区分装备；布面内铆板片另见布面甲篇。

## 一、范围与穿戴单位

板甲以成形金属板提供局部防护，按头盔、躯干、肩臂、手、腿足划分装备。板甲采用外套层；单件与组合以目录中的穿戴单位为准。

**独立件**整体穿脱；**内含构件**在所属物品内分区描述；**组合**列明所需的独立件，不再生成一件重复套装。

颈部按盔型选择锁甲帘、盔体内含颈板或独立护颚；已有相应结构时不重复加件。

## 七、分区材料与厚度

本节为游戏装备的初始设计区间，定值时结合尺寸、覆盖面积、密度、总重及活动空间调整。新增形制的局部设计厚度在各目录行内列出，共用构件仍用下表。mm均为单层金属净厚，不含重叠层、卷边、凸条或内衬。

| 构件 | 重点部位候选 | 边缘、次要部位候选 | 设计上要分开的信息 |
|---|---|---|---|
| 锅盔 | 盔顶1.5–2.0 | 盔侧1.0–1.5、帽檐1.0–1.5 | 单体成形不意味着各处等厚 |
| 尖顶盔 | 盔顶与前额2.0–2.5 | 盔侧、后脑1.2–1.8 | 可选低碳与中碳，不能用厚度直接推出热处理 |
| 猪面面甲 | 迎击前区1.5–2.0 | 下侧与边缘1.0–1.5 | 呼吸孔与眼缝是孔隙，不能算薄钢 |
| 胸板 | 中心胸区1.8–2.5 | 胸侧1.2–1.8、腹下缘1.0–1.5 | 前胸、腹与侧面分别记录；不声称这些值保证挡箭 |
| 背板 | 上背1.2–1.6 | 下背、边缘1.0–1.3 | 不强制与胸板同厚 |
| 腰裙 | 条片1.0–1.3 | 边缘与小连接片0.8–1.0 | 重叠处是多层几何，不能全裙平均翻倍 |
| 肩、上臂、前臂壳 | 主受击面1.2–1.6 | 内壳与活动片0.8–1.2 | 前后壳分区；腋窝与肘窝没有板的地方保持无板 |
| 肘杯、膝杯 | 杯体1.3–1.8 | 侧翼1.0–1.3、连接片0.8–1.0 | 侧翼不等于后窝封闭 |
| 手甲 | 手背1.0–1.4 | 袖口0.8–1.2、指片0.6–1.0 | 皮掌单独说明，不能按金属指背的厚度覆盖 |
| 大腿、胫甲 | 前片1.2–1.6 | 侧、后壳0.8–1.2 | 开背与闭合式覆盖、用料差异 |
| 铁鞋 | 脚背与趾片0.8–1.2 | 踝活动片0.6–1.0 | 底部无板，不以铁鞋外形推算完整钢鞋重量 |

## 八、配装与装备关系

| 配装/装备 | 成员与穿戴单位 | 替代与搭配 |
|---|---|---|
| 头部方案 | 锅盔、开面尖顶盔、面甲尖顶盔、巨盔等各为一件 | 根据视野、面部覆盖与重量择一；面甲属于对应头盔内部构件 |
| 尖顶盔颈部组合 | 一件尖顶盔＋一件匹配锁甲帘 | 盔保护头，帘补颈肩；无需再重复加同覆盖护领 |
| 躯干方案 | 胸甲单件，或胸甲＋背甲两件；腰裙并入所属甲体 | 胸甲方案与同部位布面主甲择一，肩臂另选 |
| 单侧肩臂组合 | 护肩＋上臂甲＋肘甲＋前臂甲，共四件 | 左右分别配；开背/双壳前臂甲择一，手甲另配 |
| 单侧腿足组合 | 大腿甲＋胫甲＋铁鞋 | 连膝大腿甲自带膝杯，不再计一件独立膝甲；胫甲两种构造择一 |
| 手部 | 单手手甲，袖口、手背和指片内含 | 分指与连指方案择一；不并入前臂甲 |
| 萨莱特头部组合 | 萨莱特盔＋板甲护颚，共两件 | 抬面甲时前脸开放；不再附加同覆盖锁甲帘作为默认成员 |
| 西亚头部组合 | 圆锥护鼻盔或包巾形盔一件＋匹配锁甲帘一件 | 两种金属盔择一；普通布缠头属于衣物，不是另一层金属盔 |
| 西亚局部肢体组合 | 护臂连手背甲每侧一件＋共用胫甲每侧一件 | 手背已内含，不另配同覆盖整只板手甲；上臂和膝后覆盖按主甲/垫衣补充 |
| 草原札甲组合的金属盔选项 | 圆锥护鼻盔＋匹配锁甲帘 | 甲体在片甲篇；也可改选该篇札片头盔，二者不同时穿 |

单侧肩臂四件是当前物品划分。若采用整体臂甲方案，应合并替代对应成员，避免保留同覆盖的整组与分件两份物品。
