# 港口与河港

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

水运功能可以出现在渔村、集镇和大城市中。分别列出渔村、渡口聚居地、河港集镇、海港城镇与商馆区；港口是聚居地的功能或组成部分，不用船只大小直接划定城市等级。

## 二、历史原型

### 卑尔根Bryggen：贸易港区与商馆院落

Bryggen保存了与14世纪起汉萨贸易相关的港区组织：沿狭长地块布置居住、办公、仓储及后部共同活动空间。现存外观主要来自1702年火灾后的重建，不能把每栋现存建筑直接定为14世纪原件。该原型用于调查贸易港区的空间关系。[UNESCO遗产说明](https://whc.unesco.org/en/list/59/)

### Dartmouth：贸易、渔业与独立港防

Dartmouth的中世纪繁荣与贸易和渔业相关，1388年的防御堡另占港口入口位置。港区民用建筑与军事防御可分开组织，不能把所有海港都安排成沿海城堡内部的码头。[English Heritage地方与城堡史](https://production.english-heritage.org.uk/visit/places/dartmouth-castle/history/)

## 三、具体聚居地类型

| 类型 | 生计与交通功能 | 优先建筑组合 |
|---|---|---|
| 渔村 Fishing Village | 以捕鱼、加工与出售鱼货为主 | 渔民住宅、渔具棚、鱼货加工屋、储盐空间和船只修理棚 |
| 渡口聚居地 Ferry Settlement | 依赖渡运和往来旅客 | 渡夫住宅、候渡或储物建筑、旅店、马厩及条件性的收费房 |
| 河港集镇 River Port | 内河货物集散与周边交易 | 仓库、商人店宅、旅店、称量与征税场所、船工住宅 |
| 海港城镇 Seaport | 海运贸易、渔业与船舶服务 | 商馆、货栈、专业仓库、船坊、海员住宿、关税建筑和城市公共建筑 |
| 商馆区 Trading Quarter | 特定商人组织的居住、仓储和交易区 | 商人院落、账房、仓库、集会与厨房空间；可属于更大的城市 |

渔村、渡口和河港的具体原型仍需另选；不把卑尔根商馆格局缩小后宣称为所有渔村的历史复原。

## 四、典型建筑目录

| 建筑 | 主要功能 | 条件与内部空间 |
|---|---|---|
| 渔民住宅、船工住宅、海员住所 | 家庭居住或季节性住宿 | 可兼工具储存；不默认都是旅店式通铺 |
| 渔具棚、网具作坊 | 存放、修补渔网与渔具 | 晾网场为露天配套 |
| 鱼货加工屋 | 清理、腌渍、熏制或其他加工 | 按鱼种、气候与贸易方式选择工艺，不给每村配齐全部工艺 |
| 盐仓、鱼货仓 | 盐和加工鱼货储存 | 可在民宅附屋或独立仓库内，不预设机械制冷或普遍冰窖 |
| 渡夫住宅、收费房 | 渡运经营与可能的收费 | 可以合设；收费权另核 |
| 商人宅邸、商馆 | 住宿、办公、交易与组织活动 | 账房和集会厅可在院落内部 |
| 货栈、转运仓、谷物仓、酒货仓 | 暂存和分类货物 | 按实际贸易品和运输量选用，不按货物名无限拆成建筑类别 |
| 税关、秤房 | 报税、计量和检查 | 可同处一个建筑；小渡口未必具备 |
| 旅店、酒馆、马厩 | 旅客、运输人员与陆路接驳 | 与城镇篇使用同一建筑类型 |
| 造船坊、船只修理棚 | 船体制造和修理 | 露天船台、木料场和下水坡道另列设施；不默认近代干船坞 |
| 绳索作坊、帆匠坊、箍桶匠坊 | 船用耗材、货物容器制造修补 | 完整长绳场等形式的具体年代和原型须继续核查 |
| 木料棚、工具库 | 船坊材料和设备储藏 | 与船坊成组布置 |
| 港防堡、守望塔 | 守卫港口入口和观察 | 依威胁与防御组织出现；具体类型见城堡与要塞篇 |
| 教堂、礼拜堂、施济建筑 | 常住社区及往来人员服务 | 不因临海就固定同一种宗教建筑格局 |

配套设施：码头、栈桥、系泊点、岸边卸货地、船台、下水坡道、晾鱼架、晾网场、货物堆场和河岸道路。码头可以采用不同岸工形式，小渔村不必有大型石砌港池；起重设施按具体原型另核。

## 五、空间关系与细查重点

将靠岸、卸货、临时堆放、称量或征税、仓储与陆路转运串联起来。加工鱼货、修船和一般居住需要的空间不同，不能将所有建筑沿一条岸线等距排列。港区也可位于城墙外，经城门连接城市市场。

后续优先调查渔户院落、鱼货加工屋、商馆货栈、税关秤房、船坊和渡口旅店，再按不同规模核定码头与岸边设施。
