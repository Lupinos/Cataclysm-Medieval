# 农村聚居地

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

区分独立农庄、小村、村庄和庄园聚居地。农庄是居住和农业经营单位，小村与村庄是居民聚集方式，庄园则涉及土地经营和领主组织；一个村庄可以包含多个庄园，不以村庄大小判断是否存在领主。

## 二、历史原型

### Wharram Percy：村庄、庄园院落与农户地块

英格兰Wharram Percy遗址包含教堂、两处庄园遗迹、成列农户地块、谷仓等附属建筑及磨坊相关遗迹。14世纪农民长屋提供具体住宅方向；原型支持住宅与生产附屋共同组成农户院落。[English Heritage遗址说明](https://www.english-heritage.org.uk/visit/places/wharram-percy-deserted-medieval-village/history/description)

其历史还包括14世纪人口与经营变化，以及领主不再常住的阶段。因此庄园宅邸是否有人居住与村庄是否继续存在分别判断，不能以“每村必有常住领主”编排建筑。[English Heritage村史](https://www.english-heritage.org.uk/visit/places/wharram-percy-deserted-medieval-village/history/)

该原型主要支撑英格兰集中型村落；分散农庄、小村和其他地域的具体建筑原型继续另选。

## 三、具体聚居地类型

| 类型 | 居住与经营形态 | 典型建筑组合 |
|---|---|---|
| 独立农庄 Farmstead | 一户或一个经营院落，住处与农业生产紧密结合 | 农舍、谷仓、牲畜附屋、工具棚；部分可合屋 |
| 小村 Hamlet | 少量农户聚集，部分公共服务依赖邻村 | 农舍院落、储粮与畜养建筑；礼拜堂、工匠住宅按条件出现 |
| 村庄 Village | 较多农户围绕道路、绿地或公共中心聚集 | 成组农舍、教堂、牧师住宅、谷仓与磨坊；铁匠铺、麦酒屋为可选 |
| 庄园聚居地 Manorial Settlement | 围绕领主自营地、收租和管理组织 | 庄园宅邸或管事住宅、经营院、粮仓、谷仓、畜舍、相关农户 |

## 四、典型建筑目录

| 建筑 | 使用者与主要功能 | 组合及出现条件 |
|---|---|---|
| 小农舍 | 农户日常起居、做饭与储物 | 可只有少量房间，不能预设每户都有独立卧室 |
| 农民长屋 | 住宅与农业空间沿长轴组合 | 人畜分区及具体入口须按地域原型确定 |
| 富裕农户住宅 | 较多起居、储物和经营空间 | 与普通农舍保留规模和分区差异，不按墙材直接认定身份 |
| 谷仓 | 贮存与处理收获物 | 可含打谷空间；与架空、分仓或其他形式的粮食储藏建筑分别调查 |
| 粮仓 | 保护干燥粮食、限制鼠害和潮气 | 可独立，也可在其他建筑内部 |
| 牛舍、马厩、猪舍、羊棚、禽舍 | 按饲养动物提供空间 | 分开列类型，具体院落无需凑齐全部畜种 |
| 工具棚、车棚 | 储放农具、车辆与修理材料 | 可与谷仓或牲畜建筑合设 |
| 庄园宅邸 | 领主家庭起居、宴饮与管理 | 大厅、私室、厨房、酒窖为内部空间或附翼 |
| 管事住宅 | 不常驻领主的经营管理 | 可兼收租与保管账册，不要求另设市政厅 |
| 领主谷仓、什一税仓 | 储存特定经营收益或征收物 | 什一税属于具体征收制度，不把所有大谷仓都称为税仓 |
| 教区教堂、礼拜堂 | 社区礼拜 | 教区中心与附属礼拜地点分别核定，小村不必有独立教区教堂 |
| 牧师住宅 | 教士居住与生活 | 可带园地、附屋；不把遗址后世重建的住宅照搬到基准期 |
| 水磨坊、风磨坊 | 谷物加工 | 按水源、风力与地域选型；磨坊可在村外且服务多处聚居地 |
| 烤房、酿酒作坊 | 烘烤与酿造 | 公共、领主经营或住户自用须分别核查，不默认全村共用一座炉 |
| 铁匠铺 | 农具修补和常用铁件 | 可由邻村或集镇提供；不自动具备专业板甲生产设备 |
| 麦酒屋 | 家庭酿售与居民聚会 | 可与住宅合用，不必采用城镇旅店格局 |
| 鸽舍 | 饲养鸽子 | 可为独立建筑；权利与地域背景待具体核查 |

配套设施：农家院、菜园、果园、耕地、牧场、围栏、畜栏、水井、饮水池、粪堆、村绿地、教堂墓园、磨池与水渠。它们共同构成村庄生活空间，不能全算作独立房屋。

## 五、空间关系与细查重点

先把农户住宅、附屋和地块组成院落，再组织多个院落与道路、教堂及庄园的关系。谷物加工、畜养、储粮和饮水分别需要对应空间；村内缺少某类专业建筑，可以由邻近聚居地提供服务。

下一步重点调查农舍与长屋、谷仓与粮仓、畜舍、庄园宅邸、水磨坊和风磨坊，核清屋内功能与独立附屋的界线。
