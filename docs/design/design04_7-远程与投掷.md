# 策划案 004_7：远程与投掷

父案：[武器体系](design04-武器.md)。

## 一、范围与物品单位

收录弓、弩、投石索、投掷武器与配套弹药的形制。火药武器不在本轮目录展开。完整弓、完整弩各为一个独立件；弩臂、弩床、弦与释放机构为内含构件。箭、弩矢和独立上弦器是另外的使用单位，不把带附件的弩再重复列为一把套装弩。

## 二、历史原型与资料

### R1：Mary Rose 长弓与箭

Mary Rose于1545年沉没；馆方记船上发现172张长弓及2000余支完整箭，强调使用者需要力量和技能。这组遗物属于16世纪实物对照，不能直接定为1415年战场装备；本轮所读总览未给每把弓的长重、拉重和指定拉距，不填写所谓统一140磅长弓。[Mary Rose馆方武器总览](https://maryrose.org/discover/collections/the-weaponry-of-the-mary-rose/)

### R2：Met 04.3.36 复合弩

符腾堡Ulrich V伯爵的弩，纪年1460年，晚于基准期。Met研究图录记材料包括角、筋腱、桦树皮、木、象牙、骨、鹿角、麻、铁及铜合金等；约71.8×65.4cm，重2972g。这是具体贵族装饰弩，不能代表普通军用弩成本，也不能由所有材料共同出现推定它们都属于弩臂弹性层。[Met研究，Ulrich弩](https://resources.metmuseum.org/resources/metpublications/pdf/The_Metropolitan_Museum_Journal_v_44_2009.pdf)

### R3：弩的结构与上弦资料

Met《A Deadly Art: European Crossbows, 1250–1850》为木弩、复合弩、钢弩及配套结构的后续核读依据。本轮尚未选定一件1375–1425年完整样本，不将R2的配件与其他世纪钢弩拼成“1400年标准重弩”。[Met专题图录](https://resources.metmuseum.org/resources/metpublications/pdf/A_Deadly_Art_European_Crossbows_1250_1850.pdf)

### R4：箭头考古资料

《Medieval Arrowheads from Oxfordshire》讨论具体箭头及其分类问题，说明同类箭头仍有尺寸与制造差异。作为弹药选型依据，具体器物编号与测量表仍需逐项核对；不能仅凭bodkin或broadhead英文名称就给出统一穿甲值。[考古研究论文](https://oxoniensia.org/volumes/2008/wadge.pdf)

## 三、游戏武器类型与历史原型

以下各表按游戏用途分组，每行是一种具体装备候选；分组标题不另算装备。握持、距离、操作或用途的差别用于支持独立物品，装饰、颜色与单纯钢材替换不另计类型。表中定位是游戏设计建议，历史适用性按原型栏分别核实。

### 弓

|---|---|---|---|

## 四、构件与材料

| 分区 | 需记录内容 |
|---|---|
| 弓 | 弓材、弓臂形状与截面、弓梢、弦、拉重对应的拉距；弓长不直接决定威力 |
| 弩臂 | 木、角筋复合或钢，连接与包覆；弹性体材质和装饰层分开 |
| 弩床与释放 | 木床、弩机、承弦件、扳机与踏环；按具体样本确定 |
| 独立上弦器 | 腰钩、杠杆、绞盘或齿轮式分别核年代、结构及兼容；不默认每把弩都带同一套 |
| 箭与弩矢 | 箭头、杆、尾部、羽及连接；发射器匹配与质量另列 |
| 投掷器物 | 投石索的兜与绳、投矛的头柄与配重；石块重量不能套给所有弹丸 |

R4支持先按具体箭头选型，再提出窄尖头、宽刃头等弹药分支；钝头弹药尚缺本案具体原型，不直接指定为击退训练弹。箭头种类与整箭是构件和完整弹药的关系，不重复计算伤害。

## 五、使用定位与取舍

“重弩”保留为分组与统称，组内按杠杆、绞盘、齿轮三种上弦方案列具体装备，不额外增加一把无区别的通用重弩。上弦器本体仍是配套工具，弩的接口、操作流程与负担随具体方案说明；不能只是给同一把弩更换附件就重复计作三把不同弩。弩臂材质则在每种方案内部选定。

猎弓、长弓与重型战弓的划分采用本模组的拉力、匹配箭矢和使用负担方案；历史上用途与名称存在交叉。轻重投矛同样需要在整矛质量、配重、携带数量和近战可用性上形成差别，不能只改形容词。


弓的训练包含开弓、稳定、瞄准和连续射击；弩降低持续持弦负担，但仍需上弦、装填、瞄准和维护技能。高拉重不能单独证明出箭能量更高，比较时还需考虑动力行程、效率与弹药质量。

有效射击距离与最大抛射距离分开。窄尖头不保证贯穿所有锁甲或板甲，宽刃头也不自动产生固定出血效果；目标甲材、厚度、角度、距离与箭矢状态共同影响结果。

投矛需要与步矛区分投掷取向及携行数量；普通石块和可投工具保留应急用途，不为每一种投掷动作新增专用物品。弹药补给、上弦器负担和武器携行一起决定使用定位，游戏数值待具体原型参数核定后再写。
