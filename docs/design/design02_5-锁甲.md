# 策划案 002_5：锁甲与锁板甲

父案：[盔甲体系](design02-盔甲.md)。

## 一、范围与穿戴单位

锁甲按衣体裁剪、护颈形式、环结构和局部补片细分，采用普通层。锁板甲作为带硬板的整件主甲采用外套层。

**独立件**整体穿脱；**内含构件**在所属物品内分区描述；**组合**列明所需的独立件，不再生成一件重复套装。

## 七、分区材料与厚度

以下为本模组环结构的尺寸起点。尺寸单位 mm。线径只用于圆截面线材；搭接铆接处压扁，不应按圆线径描述整个搭接区。默认采用四合一编织、铆接环；全铆接与铆接／实心环交替的方案另行区分，不能仅靠外观决定。

| 候选结构 | 覆盖分区 | 环内径起点 | 圆线径/注明的板厚起点 | 材料候选与取舍 |
| --- | --- | --- | --- | --- |
| 有袖衣体 | 胸腹、背、肩、上臂、前臂与裙摆 | 6–8 | 1.0–1.2 | 低碳铁钢为初选；不同覆盖长度独立核算重量，不套用伦敦原件14kg |
| 衣体局部加强变体 | 胸上段与肩；袖、裙仍用普通环 | 5–6 | 1.1–1.3 | 通过小环／较粗线改变密度，不称为全衣“双层”；并不自动增加未加强处防护 |
| 悬挂式护颈 | 侧后颈与披肩 | 6–8 | 0.9–1.1 | 低碳铁钢；前喉若加强，另标区，不把全披肩密织 |
| 密织立领变体 | 喉与颈周；披肩独立 | 4–5 | 1.0–1.2 | 以密度与衬托维持立领；披肩可用6–8内径、0.9–1.1线径。立领与披肩分别选择环规格 |
| 腋／肘窝补片 | 板甲活动间隙 | 5–7 | 0.9–1.1 | 低碳铁钢；小环密度与活动余量同时权衡 |
| 腿具 | 大腿、小腿；足部若有则单独裁剪 | 6–8 | 0.9–1.1 | 低碳铁钢，膝后与踝部通过收放环和系结处理；不默认以薄线免除负重 |
| 独立兜帽 | 头顶、侧后头、颈肩 | 6–8 | 0.9–1.1 | 铁或低碳钢；面部开口、下缘用皮/织物包边 |
| 前开襟锁板甲衣的硬板区 | 胸背主板/侧腹小片 | 不适用 | 单片胸背1.2–1.8mm，侧腹0.8–1.2mm | 低碳或中碳钢，设计板厚；并非环线径 |
| 前开襟锁板甲衣的环接区 | 片间、袖、下摆 | 6–8 | 1.0–1.2 | 铁/低碳钢；短袖下未覆盖的前臂由另配护臂承担 |

中碳钢及其他钢材变体按总纲菜单选择，硬化状态另列；优先保留能形成明确成本与防护取舍的方案。扁环款必须另填径向宽度、截面板厚和搭接尺寸，不能拿本表圆线径直接替代。

## 八、配装与装备关系

| 配装/装备 | 成员与穿戴单位 | 替代与搭配 |
|---|---|---|
| 锁甲衣 | 衣身、袖与裙摆合为一件；立领款另含衣领 | 圆领/立领及其他裁剪为替代方案，不重复套穿多件主体衣 |
| 盔缘挂帘组合 | 一件所选头盔＋一件匹配锁甲帘 | 帘补下脸与颈肩，不包含头顶；与独立护领按覆盖选配 |
| 护领 | 密织立领与柔性披肩合为一件 | 不拆成领＋肩甲两件，已有合适衣领时可省去 |
| 板甲间隙防护 | 缝附锁甲补片并入武装衣 | 不是一件独立全袖甲；与完整锁甲衣按所需覆盖选择 |
| 单侧腿足 | 开背式或袜筒式腿具各为一件 | 方案内已有足部时不重复增加鞋套；左右分别配 |
| 锁板甲衣 | 硬板、锁环衣体、袖和下摆共同组成一件外套主甲 | 替代相应躯干主甲，内部板片不另计胸甲 |
| 古式兜帽组合 | 独立锁甲兜帽＋圆锥护鼻盔，共两件；甲衣另配 | 兜帽已护颈肩，不默认再叠挂帘；不与甲衣合成全身一件 |
| 西亚/东欧重装主体 | 前开襟锁板甲衣＋圆锥护鼻盔或包巾形盔＋匹配锁甲帘 | 锁板甲的袖和甲摆内含；护臂连手背甲、胫甲按需求另配。土耳其/波斯方向共用此甲衣，材料与装饰用变体表达 |

普通锁甲为普通层，适合与外套板甲配合。环径、线径与局部密织用作同类装备的结构变体，不把每一处加强都拆成单独护具。
