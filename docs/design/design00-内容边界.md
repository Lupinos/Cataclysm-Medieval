# 项目内容边界

## 游戏目标

以约 1375—1425 年技术背景的低魔中世纪生存世界为主体。职业、聚落、物资、敌人与战斗规则围绕这个世界设计。

## 原版内容的定位

原版物资和世界内容保留为参考与未来穿越题材的素材。未选入项目的现代物资不进入当前世界；保留资料不表示它们应持续参与游戏运行。

现阶段不制作穿越物资投放。未来按具体玩法选取物件，确认获取途径、数量、维护成本和对中世纪生存循环的影响后，再纳入世界。

## 内容取舍

保留需要的通用生存能力，逐类建设自己的装备、地图、职业、敌人、任务和获取循环。原型阶段的黑名单与内容覆写不是玩法目标，不能作为“其他来源永远不可达”的设计前提。
