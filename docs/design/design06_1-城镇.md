# 城镇

父案：[聚居地的类型](design06-建筑.md)。

## 一、范围与分类边界

收录以交易、手工业和公共服务集中的常住聚居地。集镇、普通城镇和大城市体现服务范围及职业分化；主教座城、商贸城市和城堡附城体现组织核心，可与规模类型重叠。城墙并非城镇成立的必要条件，大教堂也不按人口达到某一数字自动出现。

## 二、历史原型

### 普罗万：商贸城市与集市建筑

法国普罗万保存了与香槟集市相关的城市格局。UNESCO列出商人住宅、拱顶储藏空间、仓库、露天交易场地与宗教建筑，并说明制革、染色、布匹交易和货币兑换与贸易的联系。它为商贸城市提供原型，不代表每个集镇都具有同等专业化程度。[UNESCO遗产说明](https://whc.unesco.org/en/list/873/)

当地称为“什一税仓”的建筑原为13世纪商人住宅，曾用于室内交易，14世纪起用于什一税仓储。它说明建筑名称和用途存在时代变化，也支持商业与储藏功能结合的方案。[普罗万官方建筑介绍](https://provins.net/en/the-tithe-barn-of-provins/)

### 罗切斯特：城堡、教堂与城镇的组合

罗切斯特城堡位于有城墙的城市西南部。可据此区分城市边界与内部城堡边界；城堡、主教座堂及市民街区需要分别调查，不能把整座城归为一座扩大版军事营地。[English Heritage城堡史](https://www.english-heritage.org.uk/visit/places/rochester-castle/history/)

## 三、具体聚居地类型

| 类型 | 组织核心与识别点 | 优先建筑组合 |
|---|---|---|
| 集镇 Market Town | 为附近乡村提供定期交易与基础服务 | 店铺住宅、集市场地、旅店、教堂、普通工坊、仓储 |
| 普通城镇 Town | 常住商人与工匠较多，形成稳定商业街 | 多种店铺与工坊、教区教堂、管理场所、旅店、住宅街 |
| 大城市 City | 多街区、多教区及较高行业分化 | 多处市场、专业工坊、行会大厅、城市权力机构、不同阶层住宅 |
| 主教座城 Cathedral City | 主教座堂与教会机构构成重要中心 | 主教座堂、主教宅邸、教士住所、教会管理与教育建筑；具体制度随地域核定 |
| 商贸城市 Trading Town | 长途贸易与货物集散突出 | 商人宅邸、货栈、交易厅、秤房、兑换铺、旅店及运输配套 |
| 城堡附城 Castle Town | 民用聚居区依附城堡发展 | 堡外住宅、店铺、市场、马厩与服务工坊；军事核心另见城堡篇 |

集镇、小城市与主教座城的其他具体原型仍需继续选择；本表是本模组分类，不把普罗万的一套设施外推到所有类型。

## 四、典型建筑目录

下表为游戏选型目录；除原型段明确列出的内容外，具体建筑的时期、地域与平面仍需逐项核查。

| 建筑组 | 建筑类型 | 出现条件与主要区别 |
|---|---|---|
| 住宅 | 工匠住宅、店铺住宅、富商宅邸、贵族城市宅邸、出租住宅、简陋住宅 | 工匠住宅可包含作坊；店铺住宅可下店上居或前铺后居，不限定统一楼层 |
| 食品交易 | 面包房、肉铺、鱼铺、杂货铺、盐商铺、香料铺 | 鱼铺与香料铺依供应和消费条件；面包烤炉可位于店后 |
| 饮食住宿 | 麦酒屋、酒馆、旅店 | 分别侧重售酒、饮食社交和旅客住宿；厨房、酒窖、客房为内部空间，马厩可独立 |
| 金属行业 | 普通铁匠铺、蹄铁匠铺、武器匠铺、盔甲匠铺、锁匠铺、金银匠铺、锡器匠铺 | 依行业分化出现；小镇可由同一铁匠承担部分修理，大城才增加专业方案 |
| 木作与运输 | 木匠坊、细木匠坊、车匠坊、轮匠坊、箍桶匠坊 | 大件木作和车辆作业需要院落；不把所有木工作业各配一座行会大厅 |
| 衣物与皮革 | 裁缝铺、鞋匠铺、皮具匠铺、马具匠铺、毛皮匠铺、织坊 | 马具与鞋类、成衣与织布分别调查；住家生产与独立工坊均可选型 |
| 特殊工艺 | 陶坊、蜡烛作坊、药铺、抄写铺、装订坊 | 陶窑是配套生产设施；药铺不自动兼具现代诊所职能；玻璃生产另见生产篇 |
| 商贸仓储 | 货栈、商人仓库、市场大厅、布匹交易厅、秤房、货币兑换铺 | 依贸易量及制度选用；市场大厅与露天市场区分，钱柜不另算钱庄建筑 |
| 行业组织 | 行会大厅、商人会馆 | 集会厅、账房、库房可处于同一建筑；不要求每种职业各有独立大厅 |
| 城市管理 | 市政厅、领主或执事办公宅邸、法院、监牢、税关 | 议事、审判、收税和拘押可以合设，独立建筑依当地权力结构出现 |
| 稀有权力建筑 | 造币厂、宫廷或大型贵族府邸 | 取决于铸币权、王侯驻地等条件，不能当普通城市必备项 |
| 宗教 | 教区教堂、主教座堂、修道院、修士会院、教士住宅、礼拜堂 | 主教座堂按教区地位选用；修院不一律采用乡间大型修道院格局 |
| 救济与公共服务 | 济贫院、施济医院、学校、浴室 | 均需核具体时期和地域；施济医院可兼具收容、照料和宗教生活功能 |
| 城缘生产 | 磨坊、酿酒坊、鞣皮坊、染坊、缩绒坊、屠宰作业院 | 结合水源、火源、气味和运输选址，不规定所有行业一律在城外 |

配套设施：市场广场、街巷、水井、水槽、墓园、桥梁、排水沟，以及条件性的城墙、城门和塔楼。井、桥、墓园及城墙不是住宅或商店；守卫室、军械室、拘押室可以位于城门塔楼内。

## 五、空间关系与细查重点

以店铺临街、后部作坊和储物、上部或后院居住作为一种典型组合，同时保留独立工坊与纯住宅。市场周围集中交易与住宿，运输量大的货栈靠近可通车道路或水路。城堡、教会院落、行会院落可能有各自的入口与内部边界。

后续按住宅、饮食住宿、金属工坊、木作运输、纺织皮革、商贸管理、宗教救济等建筑组细查；先核具体建筑原型、年代和实际工作流程，再确定房间与材料。
