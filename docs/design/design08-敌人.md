# 敌人与生态体系

## 设计目标

人类组织、普通野兽与稀有奇幻生物形成不同层级的生存威胁。敌人的战斗方式、装备和产物应体现其生活方式，而不是只提高生命值。

## 人形敌人

强盗、民兵、军队和有社会组织的奇幻种族拥有真实装备、训练差异、派系关系与必要的对话。装备既决定战斗能力，也是玩家取得资源的来源。人形敌人不等于全部野外敌人。

## 野生动物与巨兽

普通野兽按生态和群体行为行动，提供肉、皮、骨与器官。巨兽具有独特身体结构、攻击方式和产物，数量稀少，承担高风险探索目标。

## 身体与受伤

可瞄准部位、独立部位血量、关键部位死亡和伤势影响行动共同构成战斗体验。具有翼、角、尾等结构的生物应有相应战术差异，避免把人类身体改名后套用到所有动物。
