# 聚居地的类型

## 一、范围与分类方式

以约1375–1425年的欧洲为主要参照，建立聚居地类型及其典型建筑目录，供后续逐类调查建筑使用。采用城镇、村庄、城堡、要塞、修道院、港口等通行名称；具体遗址是类型的历史原型，不用单个遗址的外观描述替代类型名。

规模与功能分别记录。城市可以同时是主教驻地、港口和矿业中心；城堡可以独立，也可以位于城镇之内。以下分类是本模组的选型目录，不主张它们是历史上互斥的行政等级，也不以固定人口线划分全欧洲的聚居地。

| 分案 | 收录的聚居地类型 | 主要建筑方向 |
|---|---|---|
| [06_1 城镇](design06_1-城镇.md) | 集镇、城镇、大城市、主教座城、商贸城市、城堡附城 | 住宅、店铺、工坊、市场、行会、市政与宗教建筑 |
| [06_2 农村聚居地](design06_2-农村聚居地.md) | 独立农庄、小村、村庄、庄园聚居地 | 农舍、谷仓、牲畜棚、庄园宅邸、教堂与磨坊 |
| [06_3 城堡与要塞](design06_3-城堡与要塞.md) | 设防庄园、塔楼宅邸、领主城堡、驻军要塞、关隘堡、港防堡 | 防御工事、领主居所、驻军住所、仓储与后勤建筑 |
| [06_4 修道院聚居地](design06_4-修道院聚居地.md) | 小型修院、大型修道院、修道院庄园、朝圣聚居地 | 教堂、修院生活建筑、客舍、救济与农业建筑 |
| [06_5 港口与河港](design06_5-港口与河港.md) | 渔村、渡口聚居地、河港集镇、海港城镇、商馆区 | 渔民住宅、鱼货加工、仓库、商馆、船坊与关税建筑 |
| [06_6 矿业与其他生产聚居地](design06_6-矿业与其他生产聚居地.md) | 矿村、矿业城镇、采石聚居地、盐业聚居地、林业营地、专业工坊聚居地 | 工人住所、矿务与生产建筑、燃料和货物仓储 |
| [06_7 独立建筑与野外地点](design06_7-独立建筑与野外地点.md) | 聚居区以外的独宅、经营院落、行旅节点、宗教建筑、防御据点及营地 | 按独立选址、服务对象、主要空间和附属设施列出详细目录 |

独立建筑与野外地点作为补充目录，不另设一种聚居地等级。它们可以服务或属于远处聚居地，也可以由一家人、少量工人或守军使用；不要求周围形成居民街区。

## 二、规模层次与组合

| 规模层次 | 生活组织 | 典型建筑组合 |
|---|---|---|
| 单户或单个院落 | 一个家庭、庄园经营单位或少数工作人员 | 住宅、储物、牲畜或生产用附屋；部分功能共处一栋 |
| 小型聚居地 | 几户至若干家庭，依赖邻近中心提供专业服务 | 住宅与主要生计建筑；礼拜、交易和修理可在住宅或临时场所进行 |
| 村庄或专业聚居地 | 形成持续居住的社区，有公共或领主设施 | 成组住宅、教堂或礼拜堂、生产和储粮设施；工匠依需求出现 |
| 集镇或城镇 | 为周围乡村提供交易与服务，职业逐渐分化 | 店铺住宅、专业工坊、旅店、教堂、市场及管理场所 |
| 大型城市 | 多个教区和街区，较多专业行业与权力机构 | 多处市场、行会建筑、富商宅邸、宗教院落及条件性的大型公共建筑 |

港口、矿业、朝圣等功能可以叠加在不同规模上。城堡和修道院也可以成为聚居地的组织核心：城堡本体、堡外居民区与周围村庄分别辨认，不把它们合称为一栋建筑。

## 三、细分文档的统一写法

各分案依次说明：范围与分类边界、历史原型、具体聚居地类型、典型建筑目录、空间关系与继续细查的重点。

原型记录地点、年代与资料能支持的建筑关系。早期建筑在基准时期仍可能使用；晚期改建、近代重建和后世用途另行辨认。没有核到具体原型的类型可保留通行名称，明确标作选型候选；不把同一资料扩大成全欧洲的标准配置。

建筑目录区分三层：

- **独立建筑或院落**：住宅、教堂、旅店、工坊、谷仓、城堡等，可作为整体调查。
- **建筑内部空间**：大厅、厨房、酒窖、账房、军械室等；有独立建筑证据时才另列建筑方案。
- **露天设施与构筑物**：市场广场、码头、城墙、水井、鱼塘、晾晒架等；与建筑配套列出。

“常见”表示适合该类型的典型组合，“条件性”表示依赖规模、地域、产业、权利或具体机构。每种聚居地无须凑齐一整份建筑目录。一个工匠家庭的住处、作坊和售卖处可以共用一栋房屋；同一建筑在多个聚居地出现时沿用同一名称。

## 四、建筑调查的粒度

后续对每种建筑细查其服务对象、工作流程、房间与附屋、院落、材料、楼层及周围关系，再据历史原型提出游戏选型。例如铁匠铺、盔甲匠铺、蹄铁匠铺可以因工作内容和设备不同分别调查；同一普通铁匠铺的木墙版和石墙版先作为建筑变体。

本轮建立类型与建筑目录，不预定人口、建筑数量、尺寸、搜刮等级和灾后损坏比例。冒险者工会按[已有策划](design07-冒险者工会.md)作为本世界的建筑选项，与历史行业行会分别辨认。
