# 怪物部位受伤对行动的影响

## 设计目标

在独立部位血量基础上，让伤势改变生物的行动能力。初期关注移动、视觉和近战；飞行、平衡、游泳、听觉与嗅觉随后按物种补充。

## 部位功能

- 后肢承担地面移动，前肢或口器承担扑击、抓挠、撕咬。
- 头和眼承担视觉与反应，躯干与尾参与平衡。
- 同类动物可共用身体结构思路；狼头、熊头、角头、喙和翼仍应有物种差异。

## 移动

主要行走肢体受伤使移动能力下降。尚有支撑肢体时可保留有限爬行能力；全部失能时不能主动行走。多足生物应按剩余支撑能力表现，不能套用双腿规则。

## 视觉

视器受伤降低视野，日间与夜间视觉可分别受影响。关键头部遭致命伤按部位血量规则死亡；受伤不应只降低一个无关的总体血量显示。

## 近战与撕咬

攻击所需前肢或口器受伤时，其对应攻击变弱；相关部位完全失能时，该攻击不可用。不同攻击应使用各自需要的身体结构，不能把所有近战统一绑定到前肢。

## 后续议题

翼伤如何影响起飞、滑翔与坠落，多头和多肢生物如何保留部分能力，以及不同伤势的最低行动能力，需要继续讨论。机制目标适用于玩家、NPC与怪物；具体能力计算属于实现阶段。
